# M1 사람 테스트 — 진행자용 한 장 안내

> PROTOTYPE - NOT FOR PRODUCTION. 계획: `production/playtest/m1-plan.md`(§4 배정, §5 진행, §8 대본, §11 로그). 결정 기록 D72, D75.
> 카드는 **사실 확인 전**이다. 끝난 뒤(Day 1) 정답·해설을 설명할 때도 그렇게 말한다.

## 1. 실행
- 저장소에서: `python3 prototypes/m1-timeline/build.py` → `python3 -m http.server 8000 --directory dist/m1`
- 참가자 기기(휴대폰 세로 권장)에서 `http://<이 컴퓨터 IP>:8000/index.html?study=1` 열기. 공개 호스팅은 하지 않는다.
- **한 참가자는 처음부터 끝까지 같은 기기·같은 브라우저**로 한다(기록이 그 브라우저에 저장된다). 사생활 보호 창은 쓰지 않는다.

## 2. 참가자 설정(진행자 메뉴)
0. 메뉴는 **진행자 코드 `1592`**로 잠겨 있다(열 때마다 묻는다). 참가자가 학습 중 "진행자"를 눌러도 반 구성을 볼 수 없다. 코드는 `js/config.js`의 `study.facilitatorCode`.
1. 참가자 ID에 `P1`(또는 `P2`)을 적고 **열기**.
2. 배정을 고르고 **참가자 만들기**. P1 = 방식 A(연표)에서 S1 → 방식 B(플래시카드)에서 S2. P2 = B에서 S1 → A에서 S2. 1명이면 P1만.
3. "두 반 구성 보기"는 진행자만 본다(참가자에게 카드 제목이 보이지 않게).

## 3. 순서(메뉴의 빨간 테두리 = 다음 단계)
| Day | 단계 | 참가자가 하는 일 | 끝나면 |
|---|---|---|---|
| 0 | 1. 사전 점검(pre) 12장 | 지문을 보고 **"어느 왕 때인가"**를 기준 왕 10명 중에서 고르기(모르면 "모르겠다") + 근거 한 줄, 정답 안 보임. 목록에 없는 왕 때의 일이면 그 앞에 즉위한 왕을 고른다(화면에 적혀 있음) | "점검을 마쳤습니다" → 진행자 메뉴로 |
| 0 | 2·3. 첫 방식, 두 번째 방식 학습 6장씩 | 세션 3회. 세션 사이 결과 화면에서 잠깐 쉰다 | "학습 세션 3회를 마쳤습니다" |
| 0 | 4. 즉시 후테스트(post0) 12장 | pre와 같은 화면 | |
| 1 | 5. 재인출(post1) 12장 | 24±6시간 뒤. 메뉴에 경과 시간이 나오고 18~30시간 밖이면 빨간 경고(막지는 않음) | "모든 단계를 마쳤습니다" |

- 각 단계 화면 오른쪽 위 **진행자** 버튼으로 메뉴에 돌아온다. 도중에 닫아도 다시 열면 이어서 한다(학습 세션은 1장 이상 했으면 그 세션을 끝난 것으로 친다).
- 도래 카드가 없으면 "다음 세션으로"가 나온다(하루가 지난 것으로 셈, 세션 3회에 포함).
- 연표 칸 고르기는 방식 A 학습에만 있다. 테스트(pre·post0·post1)는 두 방식에 중립인 왕 고르기다(D74-2).
- **재학습 표시**: 상자 1(처음 보는 카드 포함)에서 틀리거나 "몰랐다"를 누르면 표시가 붙고, 단서 없이 2번 연속 맞혀야 상자 2로 오른다. 두 방식에 똑같이 적용된다. 3세션 안에서 최대 상자는 3이다.
- 테스트 모드에는 처음 안내 화면이 없다. 조작은 진행자가 대본으로 한 번 설명한다(m1-plan §8). 참가자에게 "검증 전 초안이니 사실로 외우지 말 것"을 알린다.
- 설명은 1회, 시작 후 도움·정답 확인 금지(m1-plan §8). 버그로 멈추면 개입하고 기록한다.

## 4. 로그 내보내기
- 메뉴의 **기록 내보내기(JSONL)** → `m1-study-P1-YYYYMMDD-HHMM.jsonl`. Day 0 끝과 Day 1 끝에 한 번씩 받는다(Day 1 파일이 전체를 포함).
- 줄마다 JSON 하나, 필드: `ts_ms, participant, phase(pre/learn/post0/post1), arm(A/B/-), session_index, card_id, slot_chosen(A 학습: 고른 칸의 앞 앵커 id), king_chosen(테스트: 고른 기준 왕 앵커 id, "모르겠다"는 null), self_rating(B: knew/didnt_know), correct, clue_used, box_before, box_after, near_miss(A: 한 칸 차이, 테스트: 이웃 왕), ms_on_card, relearn(세션 끝 재도전), reason_text(테스트만)`. 쓰지 않는 필드는 null.
- 고국원왕 전사(src-05)는 기준 왕 목록에 고국원왕이 없어 정답이 미천왕이다(D75). 분석에서 따로 표시한다. 서안평(src-03)도 따로 표시한다(평가 보고서).
- 다 받은 뒤에만 **이 참가자 기록 지우기**(두 번 확인). 참가자마다 저장이 따로라 지우지 않아도 다음 참가자와 섞이지 않는다.
