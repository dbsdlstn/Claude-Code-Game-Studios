# M1 프로토타입: 사료 카드 + 왕대 연표 + 간격 반복 (PROTOTYPE - NOT FOR PRODUCTION)

**상태**: 진행 중(엔진과 화면 완성, 실제 데이터·Leitner 명세 대기). 결정 기록: `docs/decision-log.md` D56, D59.

## 검증할 가설
한능검 심화 수험생에게 "이름 없는 사료 지문을 읽고 한 나라의 왕대 연표 사이에 꽂기 + 단서 비용 + Leitner 간격 반복"이
**같은 내용을 플래시카드로 외우는 것보다 낫다**(더 오래 기억하고, 순서·왕대를 근거로 말할 수 있다). 판단은 사람 테스트로 한다(D56 ④).

## 실행
저장소 루트에서 정적 서버를 띄운다(실제 데이터 경로 `../../assets/...`를 읽기 위해 루트에서 띄운다).

```sh
python3 -m http.server 8000
```
→ http://localhost:8000/prototypes/m1-timeline/ (휴대폰 세로 화면 기준, 데스크톱도 됨)

- 데이터: `js/config.js`의 `dataUrls` 순서로 찾는다. 기본은 콘텐츠 세션의 고구려 초안 `assets/data/cards/v2-draft/goguryeo-m1.json`(사료 카드 12장, 왕 즉위 기준 카드 5장, D58), 없으면 `data/sample.json`(이 세션의 임시 6장, 테스트용). `?data=경로`로 고정, `?seed=7`로 카드 순서 고정.
- 형식 차이는 `js/data.js`(로더) 한 곳에서 흡수한다. 스키마 v2가 확정되면 여기만 고친다.
- 지금 데이터는 전부 사실 확인 전이다. 화면 아래에 "사실 확인 전 카드입니다"를 늘 표시한다.

## 조작
- 위: 사료 카드(이름 숨김). **단서 보기**를 누를수록 이번 정답의 승급 폭이 준다(+2 → +1 → 0, 화면에 표시).
- 아래: 왕대 연표. 기준 카드 사이의 **틈(＋ 여기에 꽂기)**을 누르면 꽂힌다. 데스크톱은 카드를 끌어 놓아도 되고, 키보드는 Tab으로 틈에 가서 Enter.
- 정답이면 이름·연도·왕·해설·출처 공개, 오답이면 맞는 자리와 해설. 놓은 카드는 연표에 들어가 이후 틈이 잘게 나뉜다.
- 관계 단서의 `[기준 카드]`를 누르거나 포커스하면 연표에서 그 줄이 강조된다.
- 세션(최대 8장)이 끝나면 결과와 다음 세션 복습 수. **숙련 도감**: 상자 2 동, 4 은, 5 금.
- 학습 기록은 브라우저에 저장(새로고침해도 이어짐). 도감의 "학습 기록 초기화"(두 번 확인)로 지운다.

## 규칙 수치(초기값, `js/config.js` 한 곳)
| 항목 | 값 |
|---|---|
| 세션 크기 | 8장(카드가 적으면 있는 만큼) |
| 상자 | 1~5. 처음 보는 카드는 상자 1 기준 |
| 정답 승급 | 단서 0개 +2, 1개 +1, 2개 이상 0 |
| 오답 | 상자 1 |
| 재출제 간격(세션) | 상자 1:1, 2:2, 3:4, 4:8, 5:16 |
| 세션 구성 | 복습할 때가 된 카드(밀린 것·낮은 상자 먼저) → 새 카드 → 그래도 모자라면 곧 돌아올 카드 |
| 숙련 | 동 상자≥2, 은 ≥4, 금 5 |
