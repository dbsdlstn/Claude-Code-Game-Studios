# M1 플레이테스트 계획: 사료 카드 + 왕대 연표 + 간격 반복 vs 플래시카드

> **작성**: 2026-11-05(메인 디렉터 위임 하에 사용자 질문 없이 보수적 기본값으로 작성). 사용자가 아침에 검토한다.
> **근거**: D56(`docs/decision-log.md`), 평가 보고서 3절 (C)안의 다음 3단계(`docs/reviews/evaluation-hanneungeom.md`), 브리프 v3(`design/game-brief.md`), `design/card-data-schema-v2.md`, `design/leitner-spec.md`.
> **이 문서가 정하는 것**: 무엇을 검증하는가, 누구와 어떻게, 무엇을 재는가, 어떻게 판정하는가. **프로토타입 자체는 이 문서의 범위가 아니다**(요건만 11절에 적는다).
> **v2.1 계획과의 관계**: 이전 계획(`production/playtest/v2.1-plan.md`)은 v0 보드의 시기 정의를 검증하는 것이었고, 이 계획은 대상 전환(D56) 이후의 새 루프를 검증한다. 진행 대본과 관찰 방식은 같은 원칙(설명 1회 뒤 개입 금지)을 따른다.

## 1. 가설과 판정하려는 것

**가설(H)**: 한능검 수험생이 같은 사료 카드를 **연표에 꽂는 루프(A)**로 학습하면, **단순 플래시카드(B)**로 학습할 때보다 (1) 놓은 칸의 근거를 말할 수 있고, (2) 다음 날에도 더 잘 기억하며, (3) 학습을 지루해하지 않는다. 같은 간격 반복 일정을 쓰므로 차이는 **상호작용(꽂기와 단서 비용)**에서 온다.

**판정 대상**: (C)안이 플래시카드보다 낫다는 평가 보고서의 가설이다. 낫지 않으면 (C)를 다시 검토한다(D56 리스크).

**이 테스트가 하지 못하는 것**: 한 번에 6장씩, 이틀 동안의 학습이다. 간격 반복의 장기 효과(상자 4~5), 대량 카드에서의 용량, 시험 점수 향상은 재지 못한다.

## 2. 비교하는 두 방식

| | A: 연표 꽂기 (C안) | B: 플래시카드 (대조) |
|---|---|---|
| 앞면 | 이름 없는 사료 지문 | 같은 사료 지문 |
| 하는 일 | 왕대 연표(앵커 10개)의 칸을 골라 꽂는다 | 지문을 읽고 속으로 답한 뒤 카드를 뒤집어 확인하고 "알았다/몰랐다"를 누른다 |
| 단서 | 1단계 구간 관계, 2단계 직접 힌트. 열면 승급 제한/강등 | 없음 |
| 뒷면·공개 | 정답 칸 표시, 제목, 연도, 왕대, 해설, 출제 주제, 출처 | 같은 내용(왕대, 연도, 해설, 출제 주제, 출처) |
| 상자와 일정 | Leitner 5상자, 세션 수 간격 | **같은 Leitner 일정.** "알았다" = 깨끗한 정답, "몰랐다" = 오답 |
| 오답 재도전 | 세션 끝에 한 번 | 같음 |
| 세션 설정 | M1 덮어쓰기: 크기 6, 첫 세션에 6장 모두 도입 | 같음 |

두 방식의 **차이는 꽂기와 단서 비용뿐**이다. 일정, 내용, 해설 분량을 같게 해서 "연표에 꽂는 일"의 효과만 분리한다.

## 3. 카드: 고구려 12장 + 왕대 앵커 10장

### 3.1 선행 조건 (사실 확인)

수험생에게 틀린 사실은 치명 결함이다(D56 8). **다음 두 가지가 끝나기 전에는 테스트를 하지 않는 것을 원칙으로 한다.**
1. 아래 12장과 앵커 10장을 **서로 다른 두 사람**이 1차 자료(한국사데이터베이스의 삼국사기 원문·역주, 광개토대왕릉비 판독문) 및 최근 기출의 표기와 대조한다. 확인자는 사용자가 정한다(사람만 가능).
2. 사료 지문은 번역문을 옮기지 않고 원문을 근거로 **직접 풀어 쓴다**(스키마 v2 V9). 풀어 쓴 문장도 위 두 사람이 확인한다.

**확인이 끝나지 않았는데 테스트를 해야 한다면**: 참가자에게 "내용은 검증 전 초안이며 사실로 외우지 말라"고 알리고, 이 테스트는 **상호작용·학습 방식 비교**로만 읽는다. 이 경우 결과가 PROCEED여도 사실 확인 전에는 M2로 넘어가지 않는다.

## 4. 참가자

- **대상**: 한능검 심화(목표 1~2급)를 준비 중인 수험생 **1~2명**. 고대사(삼국)를 한 번 이상 공부한 사람. 사용자 본인은 수험생이 아니면 내부 확인용으로만 한 번 해 보고 점수에 넣지 않는다.
- **배정**(2명일 때, 순서와 반을 교차): P1은 **A에서 S1, 이어서 B에서 S2**. P2는 **B에서 S1, 이어서 A에서 S2**. 1명뿐이면 P1 배정만 하고, 반·순서·방식이 섞인다는 한계를 보고서에 적는다.
- **사전 질문**: 한능검 응시 경험(회차, 급수), 고구려 왕대 연표에 대한 자기 평가(1~5), 평소 쓰는 학습 방식(플래시카드, 기출, 강의 등).
- 이름은 적지 않고 `P1`, `P2`로 부른다. 기록은 동의를 받은 경우에만 녹화한다.

## 7. 판정 기준 (방향 판단, 통계적 결론 아님)

참가자 1~2명이므로 사람마다 따로 보고, 같은 방향이면 확신을 올린다. **아래 기준은 이 계획이 임의로 정한 초기값이다.**

**PROCEED(스키마 v2 확정과 본 구현으로)** — 각 참가자에서 모두 만족:
1. **다음 날 유지**: A가 B와 같거나 높다.
2. **근거 점수**: A가 B보다 높다.
3. **지속 의사**: A가 B보다 낮지 않거나, 참가자가 A를 선호한다.
4. **효율**: A의 카드당 시간이 B의 2배를 넘지 않는다.

**PIVOT(루프를 고쳐 다시 테스트)** — 하나라도 해당:
- 다음 날 유지에서 A가 B보다 6장 중 **2장 이상** 낮다.
- 효율 조건을 못 지킨다(꽂기가 너무 느리다).
- 직접 단서를 습관적으로 열어 상자 1~2에 갇히는 모습이 보인다(J3).
- 칸의 해상도 한계로 "근거를 말하는" 효과가 사라진다.

**차이 없음(플래시카드와 동등)** — 조건 1~3이 모두 비슷하면: 연표 꽂기의 추가 비용이 정당화되지 않으므로 (C)를 그대로 가지 않고 총괄에 올린다. 선택지는 (a) 플래시카드 + 연표 보기 정도의 가벼운 형태, (b) 평가 보고서의 (A)안이다. 이 판단은 사람이 한다.

**KILL 검토 신호**: 두 참가자 모두 A를 싫어하고 A의 재인출이 B보다 낮으면 (C)를 접고 목표 결정으로 돌아간다.

**NOT ASSESSED**: 수험생 참가자가 0명이거나 카드 확인(3.1)이 끝나지 않은 채 사실 오류가 발견되면 PROCEED/PIVOT를 판정하지 않는다.

## 8. 진행 대본과 개입 금지

설명은 **1회**만 한다.

> "사료 지문 카드 12장으로 한능검 고대사를 공부하는 방식 두 가지를 해 보시게 됩니다. 어느 쪽이 더 잘 외워지는지 보려는 것이라, 점수를 매기는 시험이 아닙니다. 모르는 것은 모른다고 하셔도 됩니다. 생각나는 것을 소리 내어 말해 주세요. 도중에 도움은 드리지 못합니다. 시작하겠습니다."

- 시작 후 도움, 힌트, 정답 확인, 설명을 하지 않는다. 막혀서 5분 이상 진전이 없고 직접 도움을 청하면 그 사실만 메모하고 다음 카드로 넘어가게 한다.
- 질문을 받으면 "나중에 알려 드릴게요"라고만 한다.
- 버그로 멈추면 개입하고 보고서의 버그 표에 적는다.
- 소리 내어 말하기를 안 하면 "지금 무슨 생각이 드세요?"를 세션당 최대 2번만 묻는다.
- 테스트 중 정답이나 해설을 알려 주지 않는다. 모든 설명은 Day 1이 끝난 뒤에 한다.

## 11. 프로토타입 요건 (별도 빌드 세션이 만든다)

- **HTML, 모바일 세로 390px부터.** 연표는 세로 목록(앵커 10개와 칸 10개), 탭으로 칸을 고른다(끌기는 선택).

- **데이터**: 스키마 v2의 `assets/data/cards/v2/goguryeo-m1.json`(앵커 10 + 사료 카드 12). 검증 규칙 V1~V15를 통과해야 한다.

## 13. 한계와 위험

- **참가자 1~2명**: 위 판정은 방향일 뿐이다. 수험생마다 선행 지식이 크게 다르므로 사전 점검의 기준선으로 보정한다.
- **순서와 최신성 효과**: 같은 날 두 방식을 연이어 하므로 두 번째 방식이 post0에 더 가깝다. 교차 배정(P1, P2)과 Day 1 재인출로 줄이지만 참가자가 1명이면 남는다.
- **반 분할**: 6장씩이라 한 장의 차이가 17%p다. 지표는 카드 수(몇 장)로도 함께 쓴다.
- **12장 덱의 한계**: 도래 카드가 적어 세션이 비는 현상이 생기고(`leitner-spec.md` §7), 상자 4~5는 이 테스트에서 볼 수 없다.
- **칸의 해상도 한계**: 앵커 사이에 여러 왕이 들어가 "왕대 연결"이 얕을 수 있다.
- **사실 확인 미완료 시**: 3.1의 조건.
- **판정 기준은 이 계획이 정한 초기값**이며, 총괄 세션과 사용자가 검토해서 바꿔도 된다.
