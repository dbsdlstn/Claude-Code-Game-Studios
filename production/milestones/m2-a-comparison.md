### 2.3 이 환경에서 직접 확인한 것 (53bce91)
- 단위: rules 59, rewards 21, m2 10 — 전부 통과.
- e2e: `e2e` 26, `e2e-m2` 25, `e2e-study` 6, `e2e-ux` 3 — 전부 통과. `e2e-dist`는 실행하지 않았다.
- 코드 검색: "보호권" 문구 없음, "휴식권" 문구 있음, "힌트" 1건 남음.
- 검증기 기본 실행 PASS(0/0), `--release`는 전 카드 `verified:false`라 실패(정상).
- 웹 기록의 "단위 90·e2e 61 통과"와 이 환경의 합계(단위 90, e2e 60 = 26+25+6+3)는 e2e 1건 차이다(`e2e-dist` 1건으로 추정, 확인 안 함).

### 2.4 남은 위험
1. 사람 사실 확인(M2-B B1)이 전부 남음. 최소 범위 48항목(고구려 36장+앵커 12), 확인자 2명, 시간은 추정.
2. 찍기 vs 정직 XP 격차(D99): 사람 데이터 뒤 결정.
3. 작은 묶음(신라 b3·b4, 백제 b3)으로 덱이 계획보다 작다 — 하루 학습량·균형 가정 재확인.
4. 모든 시뮬레이션은 가짜 학습자 기준. 하루 세션 수·휴식 패턴은 T4에서 처음 본다.
5. 접근성은 자동 검사 범위까지만(대비, 키보드, 낭독 영역 구조). 실제 스크린리더·실기기·글자 200%는 미확인(`a11y-m2.md` 2절).
6. D168 이후 결과 화면 길이가 줄지 않으면 2일째 이후 반복 피로 위험(평가 지적).
