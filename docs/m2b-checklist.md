# M2 사람 테스트 전 체크리스트 (사용자용 한 장)

> 초안 (2026-11-05, D139). 컴퓨터 앞에서 위에서 아래로 체크하세요. 개발 쪽(웹) 항목은 진행자가 알려 줄 때까지 기다리면 됩니다.
> 시간은 **추정**이며 측정한 값이 아닙니다.

## 0. 먼저 알아 둘 것
- 테스트 시작 조건은 두 가지입니다. ① 개발 쪽이 "M2-A 완료"라고 알림(웹 남은 일: 하루 24장 XP 상한, 결과 한 화면, 저장 손상 안내 등) ② 아래 1~4가 끝남.
- **카드 내용이 사실인지 확인하는 일은 사람만 할 수 있습니다.** AI에게 시키거나 이름만 대신 적게 하지 마세요. 모르겠으면 "확인 못 함"으로 두는 쪽이 안전합니다.

## 1. 카드 사실 확인 — 최소 범위
- [ ] **최소 범위 = 고구려 카드 36장 + 연표 앵커(왕) 12개 = 48항목.** 백제·신라·지문 변형은 이번 테스트에 꼭 필요하지 않으면 뒤로 미룬다. (전체 157항목은 약 13시간 × 2명 추정)
- [ ] 확인자 **2명**을 정한다. 서로 다른 사람이고, 각자 독립적으로 합니다(상대의 메모를 보지 않기).
  - 2명을 못 구하면: 1명만 확인하고 참가자에게 "한 사람만 확인한 초안"이라고 알립니다(예외, 보고서에 적음).
- [ ] 작업표: `design/human-review-guide.md`(한 묶음 약 1시간). 고구려 항목부터 순서대로, 1순위(불확실·수정 필요)가 먼저.
- [ ] 틀리거나 불확실한 카드는 **직접 고치지 않고** `production/review/human-review-log.md`에 한 줄 적어 개발 쪽에 넘깁니다.
- [ ] 맞다고 확인한 것만 **`tools/mark_verified.py`로 기록**(먼저 실행만 보는 모드, 확인 후 `--write`).
- [ ] 끝나면 `python3 tools/validate_cards_v2.py --release`가 고구려 부분에서 오류 없이 통과하는지 확인. 정정이 남아 있으면 **테스트하지 않습니다**.

## 2. 실기기 리허설 (1회, 약 20분)
- [ ] 참가자와 **비슷한 크기의 휴대폰**(세로, 390px 안팎)을 준비한다. iPhone/Android 각 1대면 더 좋습니다.
- [ ] 빌드: `python3 prototypes/m1-timeline/build.py` → 정적 서버로 `http://<내 컴퓨터 IP>:8000/index.html` (`?study`를 **붙이지 않은** 일반 모드). 같은 와이파이여야 합니다.
- [ ] 처음부터 한 세션을 끝까지: 시작하기 → 안내 → 세션 → 결과 → 도감.
- [ ] 확인: 가로로 밀리는 화면이 없고, 버튼이 잘 눌리고, 글자가 잘리지 않는다. 이상이 있으면 화면을 캡처해 개발 쪽에 전달.
- [ ] 사생활 보호 창과 브라우저 데이터 삭제를 쓰지 않는다(저장이 사라집니다).

## 3. 참가자 모집
- [ ] 1~2명. 한능검 준비생(심화 목표). 한 명 이상은 **앱을 처음 보는 사람**이 좋습니다.
- [ ] 기간: 3~5일(권장 4일). 하루 5~10분이고, 하루 한 번을 권하되 **의무가 아님**을 알립니다.
- [ ] 모집 문구(예시, 사정에 맞게 고치세요):

  > 한국사능력검정시험(심화)을 준비 중인 분을 찾습니다. 삼국시대 사건을 시대 순서로 놓아 보는 학습 앱을 3~5일 동안 하루 5~10분씩 써 보고, 시작·마지막 날에 20~40분 대화를 합니다. 앱의 **카드 내용은 사실 확인 중인 초안**이라 시험 공부의 근거로 삼으시면 안 되고, 마지막 날 정답과 정정 내용을 알려 드립니다. 이름은 적지 않고 참가자 번호(P1, P2)로만 기록되며, 쓰기 싫은 날은 안 쓰셔도 됩니다. 화면 녹화는 동의하신 경우에만 합니다.

- [ ] 동의 받을 것: 기록 내용(학습 기록·도감 내보내기), 녹화 여부(선택), 언제든 그만둘 수 있음.
- [ ] 개인정보(이름·연락처)는 로그와 보고서에 넣지 않는다.

## 4. 공식 정보·이용 조건 (사람이 확인)
- [ ] **한능검 공식 정보**(시험 시간, 배점, 평가 목표)를 공식 사이트에서 원문으로 확인(B4). 앱 안내 문구에 쓰기 전에는 확인 전 내용을 쓰지 않습니다.
- [ ] **번역문·기출 이용 조건**(B5): 삼국사기 번역·기출 해설을 쓰는 조건(공공누리 4유형 등) 약관 전문을 직접 읽고 문제 없는지 판단. 아직 전문을 확인하지 못했습니다(D81).

## 5. 테스트 전날·당일 (진행자)
- [ ] 개발 쪽 "M2-A 완료" 알림과 빌드 버전(커밋) 기록.
- [ ] 로그 내보내기가 되는지(도감 → 기록 내보내기) 직접 한 번.
- [ ] Day 0 일정(약 40분)과 마지막 날(약 25분) 시간 잡기. 사전 질문·대본: `production/playtest/m2-plan.md`.
- [ ] 중간 점검 메시지(Day 2 저녁, 모두 같은 문장, 독촉하지 않기).

## 6. 하나라도 안 되면 (되돌림)
| 상황 | 하는 일 |
|---|---|
| 확인자 1명도 못 구함 | 테스트 연기. 사실 확인이 없는 카드로 학습 효과를 판단하지 않는다 |
| 사실 오류 발견 + 정정 전 | 판정하지 않음(NOT ASSESSED), 정정 뒤 재개 |
| 리허설에서 화면이 깨짐 | 개발 쪽에 캡처 전달, 수정 뒤 리허설 다시 |
| 참가자 모집 실패 | 1명이라도 진행하고 한계를 보고서에 적음 |
