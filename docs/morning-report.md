## 한 줄 요약
삼국시대 카드 배치 퍼즐 **한양 도감**의 초기 버전이 완성됐다. **웹 빌드는 지금 바로 플레이할 수 있다**(테스트 79개 통과). Godot 빌드는 코드와 테스트(139개)까지 작성됐지만 **한 번도 실행하지 못했다**. 카드 44장은 모두 **사실 확인 전**이다.

## 1. 무엇이 됐나
| 영역 | 상태 |
|---|---|
| 게임 규칙 | 이름을 숨긴 카드를 단서 3단계로 추리해 나라(4) × 시기(건국기·전성기·결말기) 칸에 놓는다. 라운드 12장, 먹물 5, 도감 36장 수집 |
| 웹 빌드 `web/` | 타이틀, 튜토리얼, 보드, 단서, 판정, 도감, 라운드 결과, 플레이 기록 내보내기, 진행 저장·초기화, 키보드 조작, 접근성(대비 AA, 화면 낭독 알림), itch.io용 정적 배포 빌드. 단위 41·E2E 35 등 79개 통과 |
| Godot 빌드 `src/` | 웹과 같은 기능. gdUnit 테스트 139개 작성, 문법 검사(gdparse·gdlint) 통과, 정적 리뷰 2회(높음 0). **실행·테스트는 미실행** |
| 카드 | 본 덱 44장(판정 36·기준 4·학설이 갈려 판정 제외 4), 튜토리얼 1장. 검증 스크립트 PASS. 독립 사실 대조 3회: 44장 중 일치 38·불확실 6 |
| 아트 | 아트 바이블, 고증 가이드, 카드 44장 이미지 생성 프롬프트, 유형별 대체 문양 SVG 4종, 이미지 작업 절차서 |
| 문서 | 결정 기록 D1~D37, 플레이테스트 계획서, 로드맵, 유사 게임 조사 |

화면: `production/qa/evidence/web/`(실제 데이터로 찍은 스크린샷)

## 2. 지금 플레이하기 (웹)
```bash
git clone https://github.com/dbsdlstn/Claude-Code-Game-Studios.git
cd Claude-Code-Game-Studios
git checkout claude/integration
python3 -m http.server 8000
```
브라우저로 http://localhost:8000/web/ 를 연다. 첫 실행이면 튜토리얼부터 시작한다. 자세한 조작은 `web/README.md`.

## 3. Godot로 실행하기
`docs/run-locally.md`를 순서대로 따른다. 요약하면 Godot 4.7.x 표준판으로 `godot --headless --path . --import`(첫 import가 크래시로 끝나면 한 번 더) 후 `godot --path .`로 실행한다. **처음 실행이라 오류가 나올 수 있다.** 오류 메시지를 알려 주면 고친다.

## 4. 사람이 확인할 것 (우선순위순)
1. **카드 사실 확인**: `design/content-review-checklist.md`의 "우선 확인"부터. 근거 대조 결과는 `design/fact-check-report.md`. 사료 원문과 직접 대조한 카드는 없다(2차 자료와 역주 요약 기준).
   - 판단이 필요한 6장: 시기 판단(진대법, 무령왕릉, 사비 천도, 우륵의 귀순), 출전 미확인(백강 전투 400척, 이진아시왕 16세 520년).
   - 확인이 끝난 카드는 `verified: true`로 바꾼다. 출시 빌드는 확인된 카드만 쓴다.
2. **뒤집을 만한 결정** (`docs/decision-log.md`):
   - **D2 시기 정의**: 연도가 아니라 사건 성격으로 건국기·전성기·결말기를 나눴다.
   - **D22 라운드 구성**: 칸과 무관하게 12장을 뽑는다. 빈 칸이 정답을 알려 주던 문제를 막으려는 결정이다.
   - **D37 유형 비공개**: 숨긴 카드에는 "전승·유물" 배지를 보이지 않는다. 배지만으로 14장의 시기가 드러났기 때문이다.
   - **D15 웹 빌드**: 클라우드에서 Godot을 실행할 수 없어 검증용으로 만들었다. 이대로 웹 게임으로 갈지, Godot만 남길지 정할 수 있다.
   - **D29 렌더러**: Godot 렌더러를 Compatibility로 바꿨다.
   - **플랫폼**: `project.yaml`에는 PC(Steam/Epic)로 적혀 있다. 처음에 말씀하신 "개인 학습용"과 다르면 고쳐야 한다.
3. **플레이테스트**: `production/playtest/v2.1-plan.md`. 직접 플레이한 뒤, 한국사를 잘 모르는 사람 1~3명에게 시켜 보는 계획이다. 결과 양식은 `v2.1-report-template.md`. 웹의 "플레이 기록 내보내기"로 수치를 모을 수 있다.

## 5. 남은 문제
- Godot 빌드는 실행하지 않았다(클라우드에서 내려받은 실행 파일 실행이 권한 검사에 막힘).
- 카드 이미지는 아직 없다. 프롬프트는 `design/assets/specs/`, 절차는 `design/assets/image-workflow.md`.
- 글꼴은 시스템 글꼴에 기댄다. 번들하려면 라이선스 확인이 필요하다.
- 사람이 직접 플레이한 기록이 아직 없다. 지금까지의 판단은 자동 테스트와 내부 평가 기준이다.
