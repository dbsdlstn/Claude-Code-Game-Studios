# 한양 도감 재미·완성도 평가와 한능검 1급 전환 검토

> 작성: 평가 세션, 2026-11-05. 대상: `claude/integration` 최신본(`a06c4aa`).
> 이 세션은 평가만 했다. 코드·카드 데이터·설정은 고치지 않았다.
> 사용자에게 묻지 않고 판단했다(모바일 환경). 판단 근거는 각 절에 적었다.

## 0. 먼저 읽을 것: AI 평가의 한계

- **재미를 직접 느끼지 못한다.** 아래 재미 점수는 규칙·데이터·화면에서 추론한 값이다. 사람이 한 판이라도 해 보면 이 점수보다 그 관찰이 우선이다.
- **평가한 모델은 한국사를 잘 안다.** 직접 돌린 라운드에서 단서 1단계만 보고 12장을 모두 맞혔다. 모델 점검(`clue-difficulty-precheck.md` §2)도 같은 이유로 "사람 데이터로 쓸 수 없다"고 밝혔다. 따라서 난이도, 특히 "초심자에게 얼마나 어려운가"는 이 보고서로 판단할 수 없다.
- **에이전트 4명은 같은 계열의 모델이다.** 서로 독립적으로 읽었지만, 시각이 비슷하게 겹칠 수 있다. 의견이 일치한다고 해서 그것이 옳다는 근거가 되지는 않는다.
- **한능검 정보는 웹 검색 스니펫 기준이다.** 공식 사이트 `historyexam.go.kr`는 이 세션의 네트워크 허용 목록에 없어 원문을 읽지 못했다. 확인하지 못한 항목은 "확인 못 함"으로 표시했다.
- 사람 플레이 기록은 0건이다. 카드 45장 모두 `verified: false`다.

### 평가 방법
| 평가자 | 본 것 |
|---|---|
| creative-director | 정체성, 재미의 핵심, 한능검과 양립하는지 |
| game-designer | 핵심 루프, 규칙, 난이도, 반복 플레이. `rules.js`와 카드 데이터 전체를 읽음 |
| ux-designer | 튜토리얼, 피드백, 학습 흐름, 접근성. 스크린샷 16장을 직접 봄 |
| qa-lead | 테스트를 실제로 실행, 검증기, 사실 리스크 카드 |
| 총괄(이 세션) | 웹 빌드를 Playwright로 실행해 2라운드를 진행(데스크톱 1280px에서 정답 위주로 1판, 모바일 390px에서 일부러 틀려 실패 1판), 한능검 조사, 종합 |

## 1. 현재 게임 평가

### 1.1 재미

**재미있는 것**
- **사료를 각색한 장면 묘사(단서 1).** 예: "제사에 쓸 돼지가 달아나…"(국내성 천도), "숫돌과 숯을 미리 묻어 두는 꾀"(석탈해). 이름을 지운 장면을 알아보는 "아, 그거구나"가 이 게임에서 가장 강한 감정이다(creative-director, 총괄 플레이).
- **정직한 12지선다.** 칸과 무관하게 카드를 뽑고(D22), 오답이면 카드를 소모하며(D3), 숨긴 카드에 유형을 보이지 않는다(D37). 그래서 남은 칸을 지워 가는 소거 풀이가 막혀 있다. 퍼즐 설계로서 성실하다.
- **톤.** 한지 바탕, 나라 인장, 正 낙관, 먹물 방울이 하나의 메타포로 묶인다. 정답·오답 연출(正 도장, 먹 번짐)이 분명하다(직접 실행해 확인).
- **수집 만족감.** 도감 칸이 n/3으로 채워진다.

**약한 것**
- **단서를 더 봐도 비용이 없다(지배 전략).** `revealNextClue`는 `shown`만 올리고, 단서 수(`hints`)는 통계에만 쓰인다. 점수·먹물·수집 어디에도 반영되지 않는다(`web/src/rules.js` 289~335행, 총괄이 확인). 그래서 "매번 3단계까지 다 열고 놓기"가 최선이다. "단서를 더 볼까?"라는 선택이 실제로는 의미가 없다(game-designer).
- **단서 2·3단계가 정답을 거의 말해 준다.** 기준 카드가 나라마다 1장이라, 관계 단서가 나라를 바로 정한다. "가장 강했던 때", "맨 처음" 같은 표현은 시기까지 정한다(예: `baekje-peak-01` 단서 2). 모델 점검에서 2단계 정답률(88.9%)이 1단계(91.7%)보다 낮았다. 관계 단서가 추리를 돕지 못했다는 뜻이다.
- **추리보다 인식에 가깝다.** 아는 사람은 단서 1에서 알아보고 끝난다. 모르는 사람에게는 추리할 재료가 모자랄 가능성이 크다(creative-director 추정). 브리프가 약속한 "관계로 칸을 좁히는 추리"(`design/game-brief.md`)가 일어나는 구간이 좁다.
- **유형과 시기가 겹치는 메타 요령(D41).** 신화 9장은 모두 건국기, 유물 4장은 모두 전성기다. "신기한 탄생이면 건국기, 무덤·비석이면 전성기, 대국과의 전쟁이면 결말기"라는 요령이 통한다.
- **반복할 이유가 약하다.** 미수집 카드를 먼저 뽑으므로 3~4라운드(약 30~60분, 추정)면 36장이 끝난다. 완성 뒤에는 새 목표가 없다. 단서 문장이 고정이라, 두 번째부터는 장면과 칸을 외우는 일이 된다.
- **난이도 곡선이 없다.** 카드가 무작위로 나오고, `difficulty` 값(1이 12장, 2가 22장, 3이 2장)은 모델 점검에서 실제 풀이 단계를 예측하지 못했다.

### 1.2 완성도 (초기 버전 기준)
- **웹 빌드는 초기 버전으로서 완성도가 높다.** 타이틀, 튜토리얼, 보드, 판정, 도감, 결과 화면, 저장, 키보드 조작, 대비 AA, 낭독 알림까지 한 바퀴가 돈다. qa-lead가 직접 실행한 결과 단위·일치 테스트 51개와 E2E 43개, 합계 94개가 통과했다. 보고된 97개 중 나머지 3개(`e2e-dist`)는 저장소에 빌드를 쓰기 때문에 실행하지 않았다.
- **카드 검증기는 PASS다.** 12칸 모두 3장씩이다. 그러나 `--release` 모드는 **FAIL**이다. 확인된 카드가 0장이라 출시용으로 실을 카드가 없다.
- **모바일에서 쓸 수 없다.** 총괄이 390px 폭에서 실행해 보니 문서 폭이 1100px로 가로 스크롤이 생겼다. 원인은 `web/style.css`의 `body { min-width: 1100px }`이다. 수험생은 짧은 시간에 휴대폰으로 반복 학습하는 경우가 많으므로, 한능검 목표에서는 중요한 결함이다.
- **Godot 빌드는 한 번도 실행하지 않았다.** gdUnit4(`addons/`)도 설치돼 있지 않다.
- **실패 화면에 정보가 빠졌다.** "놓지 못한 카드 n장"에 목록과 해설이 없다. 총괄 플레이에서도 확인했다.
- **튜토리얼 4/4 화면에서 머리글이 잘린다.** 스크린샷 `00c-tutorial-explain.png` 기준.

### 1.4 의견이 갈린 곳
- **재미의 원천.** creative-director는 "인식의 쾌감과 수집"을 재미의 원천으로 보고, 추리는 약하다고 판단했다. game-designer는 더 비관적이다. 지배 전략 때문에 추리가 "확인 작업"으로 무너진다고 본다. 둘 다 추정이고, 사람 플레이로 가려야 한다(4절 질문 1).
- **결정 하나의 무게.** qa-lead는 시기 체계(D45)가 교과서·시험 체계와 다르다는 점을 **높음** 리스크로 본다. 살수대첩·안시성 같은 승전이 결말기에 들어가고, 신라 결말기가 676년에서 끝나는데 실제 신라는 935년까지 이어진다. creative-director는 정의가 사람 데이터 없이 두 번 바뀐 점을 약점으로 본다. 반면 지금 목표("가볍게 복습")에서는 D45가 혼동을 줄였다는 모델 데이터가 있다(22% → 1.4%). **목표에 따라 같은 결정의 평가가 달라진다.**
- **사료 카드 재설계(C)의 비용.** game-designer는 D2·D45 작업을 상당 부분 버려야 한다고 본다. creative-director는 단서 1이 이미 사료형이라 가장 큰 자산을 살리는 길이라고 본다. 둘 다 맞는 말이다. 보드 축은 버리고 카드 문장은 살린다.

## 2. 한능검 1급 목표와의 격차

### 2.1 한능검 심화 시험 (웹 검색으로 확인한 범위)

| 항목 | 내용 | 확인 수준 |

| 구분 | 1~3급은 심화, 4~6급은 기본. 47회부터 개편 | 2차 자료 여러 곳이 일치 [1][2] |
| 문항·형식 | 심화는 5지 택1, 50문항 | 2차 자료 여러 곳이 일치 [1][2] |
| 시간 | 80분 | 2차 자료(블로그) [1]. 70분·50분이라는 다른 수치도 있다. 공식 확인 못 함 |
| 배점 | 100점 만점, 문항별 1~3점 차등 | 2차 자료 [2] |

| 빈출 주제 | 반복 출제되는 보기 지문이 있다(예: 신문왕의 관료전 지급·녹읍 폐지) [4]. 왜란·호란·조선 전기를 최다 빈출로 꼽는 강의가 있다 [5] | 2차 자료, 단편적 |
| 시행 | 2026년 77~81회. 80·81회는 심화만 시행 | 검색 스니펫 [6]. 공식 확인 필요 |
| 합격률 | 1급 15~20%라는 블로그 수치가 있다 | 신뢰도 낮음 |

**이 게임에 중요한 사실:** 고대(선사·고조선·삼국·남북국)는 50문항 중 **약 9문항(약 18%)** 이다. 지금 게임이 다루는 삼국은 그 고대의 일부라, **시험 범위의 10%대 초반**에 그친다(70회 기준 추정).

### 2.2 기존 한능검 학습 앱
- **주류는 기출 문제 풀이와 오답노트형이다.** 예: "한국사 오답노트(한능검 심화 문제&해설)" [7], "고종훈 OX 문제집"(기출 퀴즈와 개인 오답노트) [8], 기출 회차별 CBT 웹(57~80회 심화 무료 풀이, 빈출 200제를 94개 주제로 묶음) [9].
- 이전 조사(`docs/research/similar-games.md`)에서도 "토막 한국사·오늘한국사·개념 한국사" 같은 암기·사료 카드·문제 풀이 앱이 주류였다. 카드 배치 퍼즐은 찾지 못했다.
- 위 앱들의 상세 기능, 이용자 평가, 간격 반복 여부는 **확인 못 함**이다. 앱스토어 페이지에 접속할 수 없었다.
- **시사점:** 기출 풀이와 오답노트는 이미 무료로 많다. 이 게임이 그들과 경쟁할 이유는 "기출 풀이 앱이 주지 못하는 것", 곧 **사료 속 장면을 알아보는 감각과 사건의 위치(순서·왕대) 감각을 놀이로 익히는 것**에 있어야 한다.

### 2.3 격차

| 축 | 지금 | 한능검 1급이 요구하는 것 | 격차 |
|---|---|---|---|
| **범위** | 삼국(+가야) 36장 | 선사~현대 전 시대. 근현대가 약 40% | 매우 큼. 시험 범위의 약 10% |
| **판정 축** | 나라 × 게임 고유 시기 3분할(건국·전성·결말) | 왕대·세기 순서, 사건의 선후, 인물과 업적의 연결 | 큼. 시험은 "건국기냐 전성기냐"를 묻지 않는다. D2는 연도를 판정에서 일부러 뺐다 |
| **깊이·카드 유형** | 사건 중심. 신화 9, 유물 4, 인물 1 | 사료 지문, 제도(관등·토지·조세), 인물, 문화재 사진, 사회·문화 | 큼. 시험에 자주 나오는 제도·문화재(진대법, 고이왕 관등제, 칠지도)가 지금은 **판정 제외**다. 3분할 축이 시험의 핵심 내용을 밀어낸다(GD) |
| **학습 효과** | 첫 만남의 추리, 해설 1회, 미수집 우선 | 인출 연습, 간격 반복, 오답 복습 | 큼. 틀린 카드가 오히려 늦게 다시 나온다(D22). 3단계 힌트를 보고 맞혀도 수집된다. 오답 노트가 없다 |
| **문항 형식** | 칸에 끌어 놓기 | 5지 선다(사료 → 시대 특정 → 그 시대의 사실 고르기) | 중간. 단서 1을 사료 지문으로 바꾸는 것은 가깝다 |
| **사실 정확성** | 확인된 카드 0/45. 모델 대조 4회, 원문 대조 0. 출처 URL 모두 null | 시험 표준 표기(예: 이차돈 527년)와 오류 0에 가까운 수준 | 매우 큼. 수험생에게 틀린 사실은 S1 결함이다(QA) |
| **기기** | 데스크톱 전용(min-width 1100px) | 휴대폰으로 짧게 반복 | 중간 |

**격차 핵심 3가지**
1. **축이 다르다.** 게임은 "성격으로 나눈 시기"를 묻고, 시험은 "순서·왕대·연결"을 묻는다. 시대만 늘리면 이 차이도 같이 커진다.
2. **학습 장치가 없다.** 추리 재미는 첫 만남에서 끝난다. 기억을 남기는 반복(간격 반복, 오답 복습, 인출)이 규칙에 없다. 오히려 단서 비용 0이 "힌트를 보고 맞히기"를 권한다.
3. **사실 확인과 범위.** 확인된 카드는 0장이고, 범위는 시험의 약 10%다. 전 시대로 넓히면 사실 확인 비용이 카드 수에 비례해 커진다. 1인 개발에서 가장 큰 병목이다.

## 3. 발전 방향

공통 전제: 어느 안이든 **사람의 사실 확인 체계**(5절)와 **모바일 대응**이 먼저 필요하다.

### (A) 지금 정체성 유지 + 시험 대비 모드 추가
- **내용:** 나라×시기 보드는 "가벼운 복습"용으로 그대로 둔다. 별도 모드에서 카드 단서 1을 사료 지문으로, 5지 선다 문항으로 낸다. 오답 노트를 붙인다.
- **장점:** 지금 코드와 데이터를 가장 많이 재사용한다. 기존 대상을 지킨다. 오답 노트만으로도 효과가 바로 보인다.
- **단점:** 정체성이 둘로 갈라진다. 시험 모드는 이미 많은 기출 앱과 경쟁하게 된다. 3분할 축이 제도·왕대를 담지 못하는 문제는 그대로다. 범위 문제도 해결되지 않는다.
- **1인 규모:** 작음~중간. 모드 하나에 2~4주, 카드는 삼국 그대로(추정).
- **재미와 학습:** 재미는 기존 모드, 학습은 시험 모드로 나뉜다. 둘이 서로를 강화하지 않는다.
- **다음 3단계:** ① 오답 노트와 다시 풀기 큐 ② 사료형 5지 선다 모드(삼국 36장) ③ 모바일 레이아웃.

### (B) 한능검 시대 순서대로 시대 확장
- **내용:** 고조선·남북국·고려·조선·근현대 덱을 차례로 추가한다. 시대마다 보드를 만든다.
- **장점:** 범위 격차를 직접 메운다. "도감 확장"이라는 반복 동기가 생긴다.
- **단점:** 지금 축(건국·전성·결말)은 고려 이후, 특히 근현대에 맞지 않는다. 지배 전략, 곡선 없음, 메타 요령 같은 루프 결함이 카드 수만큼 커진다. 사실 확인 비용이 가장 크다. 근현대만 해도 약 20문항 분량이다.
- **1인 규모:** 큼. 시대당 카드 36~60장과 사실 확인. 전 시대를 덮으려면 수백 장이 필요하다(추정).
- **재미와 학습:** 양은 늘지만, 학습 장치가 없으면 기억 정착은 그대로다.
- **다음 3단계:** ① 시대별 축 재정의 ② 남북국 덱(삼국과 이어짐) ③ 고려 덱.

### (C) 사료 카드 중심 재설계 (보드 축을 왕대 연표로)
- **내용:** 카드 앞면은 이름 없는 사료 지문(지금 단서 1의 발전형)이다. 플레이어는 ① 사료를 읽고 ② 카드를 나라별 **왕대 연표**의 기준 카드(예: 근초고왕·광개토왕·진흥왕) 사이에 꽂는다(Timeline 방식). 관계 단서는 "이 사건보다 먼저인가 나중인가"로 바꾼다. 선택 사항으로 ③ "이 왕대에 있었던 일" 선택 문항을 하나 푼다. 단서를 열면 숙련도가 깎이고, 틀리거나 힌트를 본 카드는 **Leitner식 간격 반복**으로 다시 나온다. 도감은 숙련 도감(동·은·금)이 된다. 먹물 같은 실패 압박은 학습 모드에서 빼고, 모의시험 모드에만 둔다.
- **장점:**
  - 시험이 묻는 능력(사료 판독, 순서, 왕대 연결)과 게임의 추리가 같은 동작이 된다.
  - 단서 비용 0의 지배 전략, 시기 정의 논쟁(D2·D45), 판정 제외로 빠진 제도 카드, 반복 동기 문제를 한 번에 푼다.
  - 이미 가진 가장 강한 자산(사료형 단서 1, 삼국사기 출처, 도감·해설 UI, 검증 파이프라인)을 그대로 쓴다.
- **단점:**
  - 나라×시기 보드라는 지금의 겉모습과 D2·D45 작업 상당 부분을 버린다.
  - 사료 번역문을 쓰려면 라이선스를 확인해야 한다(D4).
  - "Timeline류"에 가까워져 독창성 점수는 내려갈 수 있다.
  - 사실 정확성 요구가 가장 높다(연도·왕대가 판정 기준이 된다).
- **1인 규모:** 중간. 규칙 엔진(`rules.js`)과 스키마 v2, 삼국 카드 재작성까지 4~8주(추정). 화면 틀과 테스트 체계는 재사용한다.
- **재미와 학습:** 첫 만남은 추리(사료로 사건 특정, 앞뒤 관계로 위치 좁히기)이고, 두 번째 만남부터는 인출 훈련이 된다. 학습이 반복의 이유가 된다.
- **다음 3단계:**
  1. **결정:** 대상을 "가벼운 복습"에서 "한능검 수험생"으로 바꿀지 정한다. 실패 압박(먹물)을 어디에 둘지도 정한다. 이어서 삼국 범위의 시험 출제 주제 목록(왕별 업적, 제도, 문화재)을 만든다.
  2. **종이(또는 HTML) 프로토타입:** 고구려 12장으로 만든다. 구성은 왕대 연표 배치, 사료 앞면, 단서 비용과 간격 반복이다. 수험생 1~2명에게 단순 플래시카드와 비교하게 한다(근거를 말할 수 있는지, 1단계 정답률, 하루 뒤 재인출).
  3. **효과가 보이면:** 카드 스키마 v2(왕대, 연도, 사료문, 시험 태그, 숙련 상자)와 간격 반복 명세를 쓴다. 웹 빌드에 구현한 뒤 남북국 → 고려 순으로 확장한다(B를 나중에 흡수).

## 4. 추천안: (C), 삼국 범위에서 먼저 검증

**이유**
- 네 평가자 중 creative-director와 game-designer가 각자 (C)를 골랐다(삼국에서 먼저 검증, 확장은 나중). qa-lead와 ux-designer의 지적(시기 체계와 시험 체계의 불일치, 오답 복습 부재, 간격 반복)도 (C)에서 함께 풀린다. 단, 이 일치는 같은 계열 모델들의 의견이라 사람 검증 전까지는 가설이다.
- (A)는 목표를 바꾸는 결정을 미루는 것에 가깝다. 시험 모드는 이미 흔한 기출 앱과 경쟁하게 된다.
- (B)를 먼저 하면 검증되지 않은 루프의 결함과 사실 확인 비용이 카드 수만큼 커진다. 1인 개발에서 가장 위험한 순서다.
- (C)는 "이름 없는 사료를 읽고 사건을 알아내 위치를 정한다"는 하나의 동작으로 재미와 시험 대비를 겹친다. 정체성 이름("추리형 카드 퍼즐")도 유지된다.

**부수 권고** (어느 안이든 유효)
- **웹에 집중하고 Godot은 보류한다.** 실행 증거가 있는 쪽은 웹뿐이다. 두 벌을 유지하는 비용이 계속 늘고 있다(qa-lead). Godot은 로컬에서 한 번 실행해 결과만 기록하자.
- **모바일 레이아웃을 먼저 고친다.** `min-width: 1100px`을 없애고 세로 배치를 만든다.
- **지금 덱으로도 할 수 있는 작은 개선:** 오답 노트, 실패 화면의 놓지 못한 카드 목록, 튜토리얼에 결말기 예시 추가, 해설을 다 읽은 뒤 넘기는 "다음 카드" 버튼.

### 사람이 먼저 확인해야 할 것
1. **목표 결정(사용자).** 대상을 수험생으로 바꾸는가? 바꾸면 브리프의 대상, 범위 밖 목록("시간 제한과 점수 압박"), 플랫폼(`project.yaml`의 PC/Steam)도 함께 바뀐다.
2. **지금 빌드로 하는 짧은 플레이테스트.** 본인 1회, 그리고 가능하면 한능검 준비생 1~2명. 볼 질문은 다음과 같다.
   - 단서 1만 보고 맞힌 카드에 대해 "왜 그 칸인지" 근거를 말할 수 있는가, 아니면 알아보고 찍었는가? (재미의 원천이 추리인지 인식인지)
   - 단서 2(관계)를 열었을 때 "좁혀진다"고 느끼는가, "헷갈린다"고 느끼는가?
   - 오답 뒤에 해설을 실제로 읽는가? 결과 화면의 "오답 다시 보기"를 펼치는가?
   - 결말기와 전성기 사이에서 망설이는가? 수험생이라면 "연도로 판단했다"고 말하는가? (시기 체계가 시험 지식과 충돌하는지)
   - 한 라운드 뒤 같은 사건을 기출 형식 사료 문항으로 냈을 때, 플레이 전보다 더 맞히는가? 하루 뒤나 1주 뒤에는?
3. **사실 확인 체계.** 누가 어떤 1차 자료로 확인할지 정한다(5절). 이것이 정해지지 않으면 어느 안도 출시할 수 없다.
4. **공식 시험 정보 확인.** `historyexam.go.kr`에서 심화 시험 시간·배점·평가 목표를 원문으로 확인한다. 이 세션에서는 접속하지 못했다.

## 5. 한능검 대비 앱으로 바꿀 때의 품질 게이트 (qa-lead 제안 요약)
- **2인 확인:** 한국사 전공자 또는 1급 보유자가 1차로 확인하고, 다른 1명이 교차 확인한다. `verified_by`에 두 명 모두 적는다. 모델 대조는 보조 자료로만 쓴다.
- **1차 자료:** 국사편찬위원회 한국사데이터베이스(삼국사기·삼국유사 원문과 역주), 중국 정사 원문, 비문 판독문. 출처는 권·조 단위까지 적는다.
- **기출 대조:** 최근 기출의 표기를 정답 필드로, 이설을 별도 필드로 둔다(예: 이차돈 527년). 기출에 없는 사건은 "시험 범위 밖"으로 표시한다.
- **검증기 추가:** 출처 URL이 없으면 release 실패(R10). 카드 문구가 바뀌면 `verified`를 자동으로 false로 되돌린다.
- **오류 신고 버튼:** 사실 오류는 S1으로 분류하고, 확인 전까지 해당 카드를 출시 세트에서 뺀다.
- qa-lead가 짚은 사실·분류 리스크 카드(추정): 무령왕릉·사비 천도의 시기 분류, 이차돈 연도 병기, 가라왕 하지(판정 제외 검토), 이진아시왕 "16대"와 원문 "16세"의 표현 차이, 가야금의 "당(唐)" 표기.
