# UI 글꼴

한글 UI 글꼴을 여기에 `ui_font_kr.ttf`로 두면 게임이 이 글꼴을 쓴다
(경로는 `assets/data/config/game_config.json`의 `ui_font_path`).
없으면 시스템 한글 글꼴(Noto Sans CJK KR, 맑은 고딕, Apple SD Gothic Neo, 나눔고딕 등)을 찾는다.
그것도 없으면 화면 위쪽에 안내가 뜨고 한글이 네모로 보일 수 있다.

권장: Noto Sans KR (SIL Open Font License 1.1). 라이선스 파일(OFL.txt)을 함께 둔다.
글꼴 파일은 아직 저장소에 넣지 않았다(decision-log D17).
