# 웹 빌드 아트 검수 메모

> **날짜**: 2026-11-04
> **대상**: `web/` 웹 플레이 빌드(브랜치 `claude/integration` ecd87b8 병합 상태)
> **기준**: `design/art/art-bible.md`
> **방법과 한계**: 웹 세션이 남긴 스크린샷(`production/qa/evidence/web/`)과 `web/style.css`의 토큰을 읽어 대조했다. **이 세션에서 웹 빌드를 직접 실행하지는 않았다.** 스크린샷은 `01-board`, `02-clues-expanded`, `03-correct`, `04-wrong`, `09-dogam-full`을 열어 보았고, `00*`(타이틀·튜토리얼), `03a`, `04a`, `05*`, `06`, `07`, `08`은 열어 보지 못했다. 대비 비율 계산, 모바일 폭, 다크 테마 화면, 글꼴이 실제 사용자 환경에서 어떻게 보이는지는 확인하지 못했다.

## 1. 요약

웹 빌드는 바이블의 한지·먹 톤, 시기 정의 표기, 정답/오답의 색 외 보조 표시를 대부분 따르고 있다. 가장 큰 어긋남은 **일러스트 영역과 대체 문양이 전혀 없다는 점**과, **숨김 상태 카드에 유형 배지가 정답 단서로 작동한다는 점**이다.

## 3. 어긋난 것

### 3.1 색 hex

| 역할 | 바이블 | 웹(`web/style.css`) | 차이 |
|---|---|---|---|
| 바탕(한지) | `#EFE6D2` | `--paper #efe5cf` | 거의 같음 |
| 칸(옅은 한지) | `#F7F0DE` | `--paper-2 #f6efdd` | 거의 같음 |
| 기준 카드 | `#E3D6B4` | `--paper-3 #e6d8b8` | 거의 같음 |
| 글자(먹) | `#2B2118` | `--ink #2a211a` | 거의 같음 |
| 보조 글자 | `#5B4A35` | `--ink-soft #5c4c3a` | 거의 같음 |
| 선 | `#8A6D3B` | `--line #9c8058` | **웹이 더 밝다** |
| 금 | `#C79A2E` | `--gold #b88a2e` | 웹이 약간 어둡다 |
| 정답 칸 배경 | `#CFE8C4` | `--celadon-soft #d6e6d3` | 웹이 더 옅다 |
| 오답 칸 배경 | `#F3C4C0` | `--seal-soft #f1d3c9` | 웹이 더 옅다 |
| 고구려색 | `#A23B2A` | `--seal #a33a2a` | 같은 값이지만 웹에서는 **나라색이 아니라 낙관/강조색**(기준 라벨, 정답 도장, 선택 테두리)으로 쓰인다 |
| 백제색 | `#2F5D7C` | `--indigo #2f4a63` | **다른 색**(웹이 더 어둡다) |
| 가야색 | `#4F7A55` | `--celadon #4f7a5a` | 거의 같음 |

선, 정답·오답 배경, 백제 청이 뚜렷이 다르다. 나머지는 눈으로 구분하기 어려운 차이다. 어느 쪽이 기준인지 정해야 한다(제안 3).

### 3.2 글꼴
- 토큰은 `--serif: "Noto Serif KR", "Nanum Myeongjo", ...`와 `--sans: "Noto Sans KR", ...`로 바이블 방향과 일치한다.
- 그러나 **`@font-face`나 글꼴 파일 번들이 없다**(CSS에 해당 선언 없음). 사용자 기기에 해당 글꼴이 없으면 대체 글꼴로 보이고, 제공된 스크린샷의 제목 "한양 도감"도 세리프가 아니라 고딕 계열로 보인다(렌더링 환경 의존, 확인 필요).
- 글꼴 라이선스는 바이블에서 이미 "번들 전에 확인"으로 남겨 두었고 해결되지 않았다.

### 3.3 카드 레이아웃
| 바이블 §7 | 웹 |
|---|---|
| 5:7 카드, 상단 4:3 일러스트 영역 | **일러스트 영역 없음.** 카드는 왼쪽의 가로 패널이다(비율 5:7 아님) |
| 숨김 상태: 먹 번짐과 큰 "?"가 일러스트 영역을 덮음 | "? 이름 숨김" 제목과 단서 목록만 있음 |
| 공개 상태: 일러스트가 번짐을 걷고 제목과 `date_label` 표시 | 정답 카드에 제목, "신라 건국기 · 전승 1세기", 해설이 표시됨. 일러스트 없음 |
| 모서리 인장(나라), 공개 후에만 | 인장 없음. 대신 **유형 배지**("전승", "사건")가 숨김 상태에서도 보임 |
| 보드 행 머리글에 인장 | 행 머리글은 세로로 쓴 나라 이름(고/구/려)만 있음. 나라색 없음 |
| 도감: 채워진 칸은 일러스트 썸네일 | 도감은 이름 목록(○ + 제목)만 있음 |

### 3.4 대체 문양
`assets/art/placeholders/*.svg`는 웹 코드 어디에서도 참조되지 않는다(`web/src`, `web/index.html`, `web/style.css`에서 `placeholder`·`.svg`·`image` 사용 없음. `web/src/rules.js`는 `image` 필드를 검증만 한다). 카드에 `image`가 있어도 현재 화면에는 나오지 않는다.

### 3.5 테마
`web/style.css`에는 `prefers-color-scheme`이나 `data-theme` 규칙이 없다(검색 결과 0건). 바이블 §4.4의 다크 테마는 웹에 구현되어 있지 않다.

### 3.6 정답 도장 글자
정답 도장이 한자 "正"이다. 이미지 안 글자 금지 규칙(§8)은 일러스트 파일에 대한 것이라 위반은 아니지만, 한국사를 잘 모르는 테스터가 뜻을 모를 수 있다. 같은 정보가 ○와 "정답" 글자로 이미 제공되므로 기능상 문제는 없다.

## 4. 개선 제안 (5개, 우선순위순)

1. **숨김 상태 카드의 유형 배지를 없앤다. (높음, 플레이테스트 G5, D27)**
   판정 카드 36장 중 `myth` 9장은 전부 건국기, `artifact` 4장은 전부 전성기, `person` 1장은 결말기다. "전승" 배지가 보이면 36장 중 14장의 시기가 사실상 드러난다. 유형은 정답 공개 후(해설 카드)에만 표시한다. 바이블은 이미 이에 맞게 고쳤다(§3, §7). 단, 이번 플레이테스트는 현재 상태 그대로 두고 관찰하도록 계획서에 적었으므로, 먼저 숨기고 테스트할지는 사용자가 정한다.

2. **일러스트 영역과 대체 문양을 연결한다. (높음)**
   카드 패널 상단에 4:3 영역을 만들고, 숨김 상태에서는 먹 번짐과 "?", 공개 후와 도감에서는 `image`가 있으면 그림, 없으면 `type`별 대체 문양(`assets/art/placeholders/`)을 보여 준다(바이블 §7, §7.1). 이미지 생성 전에도 도감이 비어 보이지 않게 하는 가장 큰 개선이다.

3. **색 토큰을 한 곳으로 정하고 글꼴을 번들한다. (중간)**
   선·정답/오답 배경·백제 청 3곳이 바이블과 다르다. 바이블 값에 웹을 맞추거나, 웹 값이 낫다고 판단하면 바이블을 고쳐서 두 문서가 같은 hex를 갖게 한다(Godot도 같은 값을 쓰므로 한 쪽만 고치면 두 빌드가 갈라진다). 글꼴은 라이선스 확인 후 번들하거나, 대체 글꼴 목록으로 충분한지 결정한다.

4. **보드 행 머리글에 나라 인장과 나라색을 더한다. (중간)**
   바이블 §3과 §4.2의 인장과 나라색이 현재 없다. **카드가 아니라 행 머리글**에 둔다(카드에 두면 정답을 알려 주므로, 카드에는 공개 후에만 둔다). 행 머리글은 정답이 아니라 선택지이므로 누출이 아니다. 시각적 구분이 좋아지고 색각 이상 대비는 인장 글자가 맡는다.

5. **2단계 관계 단서가 가리키는 기준 카드를 보드에서 강조한다. (낮음, G2 보조)**
   2단계 단서의 "[박혁거세 신화]" 같은 참조가 파란 글씨로 표시된다. 이 글씨를 누르거나 포커스하면 해당 기준 카드가 놓인 칸이 반짝이도록 하면, "관계로 칸을 좁히는" 추리가 눈에 보인다. 이 상호작용이 이미 구현되어 있는지는 스크린샷만으로는 알 수 없었다(확인 필요).

## 5. 이번 검수에서 바이블을 고친 곳
- §3 "나라 인장"과 §7 카드 레이아웃: 숨김 상태에서는 인장을 표시하지 않는다고 명시했다. 원래 문구는 카드 모서리에 인장을 두라고만 해서 정답을 알려 주는 설계였다.
- §3에 "정답을 알려 주는 표시 금지" 항목을 추가했다(유형 배지 포함).
