# 한국사능력검정시험 기출문제 이용 조건

- 상태: 웹 검색 결과 정리(2026-11-05). 결정 기록 D79, D81.
- **결론**: 기출 문항을 카드에 옮기거나 고쳐 쓰는 것은 허용 범위가 확인되지 않았고, 확인된 범위로는 **상업적 이용과 변경이 금지**된다. 그래서 D79 원칙(기출은 출제 주제·빈도의 근거로만 쓰고 문장·선지·자료를 복제하지 않는다)을 그대로 유지한다. 카드에는 기출 회차 번호만 `source_ref.exam_rounds`에 적는다.

## 확인 못 한 것

- historyexam.go.kr의 이용약관 전문(검색 결과에 나오지 않음, 이 세션에서 사이트를 직접 열지 못함).
- 공공데이터포털 자료가 아닌 사이트 자료실 문항의 공공누리 유형.
- 이 게임이 무료/유료 중 어느 쪽이 될지에 따른 판단(상업적 이용 여부). 출시 형태가 정해지면 국사편찬위원회에 직접 문의해야 한다.

## 이 프로젝트에서의 원칙 (D79 유지)

1. 기출 문항의 문장, 선지, 사진·도표 자료를 카드나 화면에 옮기지 않는다(변경 후 이용도 포함).
2. 기출은 **어떤 주제가 자주 나오는가**를 정하는 데만 쓴다. 근거는 회차 번호로만 남긴다.
3. 카드 지문은 원문 사료(삼국사기·삼국유사·금석문)를 근거로 직접 쓴다.
4. 사진 자료를 쓰게 되면 원저작자 라이선스를 따로 확인한다(D4, 카드의 `image_license`).
