# 고구려 시험 출제 주제 (한능검 심화 대비, M1)

- 상태: 초안. decision-log D56(한능검 1급 대비 전환), D58.
- 근거: 웹 검색 결과(대부분 2차 자료: 한국민족문화대백과 요약, 수험 정리 글, 위키류). **사료 원문 대조와 기출 문항 대조는 하지 않았다.** "자주 나온다"는 수험 정리 글의 서술을 따른 것이고, 회차별 출제 빈도 통계는 확인하지 못했다.
- 연도는 삼국사기 기년이 기본이다. 다른 기록과 다르면 따로 적었다.
- 표의 "카드"는 `assets/data/cards/v2-draft/goguryeo-m1.json`에 사료 카드로 넣었는지 표시한다.

## 왕대 앵커 (연표 기준 카드, 9개)

앵커 연도는 수험서·교과서에서 널리 쓰는 표기 하나로 정하고 다른 기년은 병기한다(D60). 광개토왕 391~412(비문)와 장수왕 413(삼국사기)처럼 수험 표기 자체가 기년 기준이 섞여 있다.

연표에서 카드를 꽂는 기준점은 **즉위 연도**로 잡는다(재위 기간 안의 사건은 그 왕의 즉위보다 나중, 다음 앵커 왕의 즉위보다 먼저).

| 앵커 | 즉위 | 고른 이유 |
|---|---|---|
| 동명성왕 | 전승 기원전 37 | 건국 기준점 |
| 태조왕 | 53 | 동옥저 정복(56)의 왕 (D62 추가) |
| 고국천왕 | 179 | 진대법(194)의 왕 (D62 추가) |
| 동천왕 | 227 | 서안평 공격(242)의 왕 (D62 추가) |
| 미천왕 | 300 | 낙랑군 축출(313)의 왕 (D62 추가) |
| 소수림왕 | 371 | 체제 정비(불교·태학·율령)의 기준. 고국원왕 전사(371)와 같은 해라 경계 확인용 |
| 광개토왕 | 391 (재위 391~412, 비문 기년. 삼국사기 392~413은 병기) | 정복 활동의 기준 |
| 장수왕 | 413 (삼국사기 기년. 비문 기년으로 계산하면 412, 병기) | 평양 천도와 남진의 기준 |
| 보장왕 | 642 | 연개소문 집권과 멸망기의 기준 |

앵커는 최대 9개(D62). 고국원왕 전사(371)는 미천왕~소수림왕 틈, 살수대첩(612)은 장수왕~보장왕 틈에 놓인다(고국원왕·영양왕 앵커 없음).

대안: 영양왕(590)을 넣으면 413~642 사이(장수왕 평양 천도~살수대첩)가 나뉜다. 카드가 늘면 고려한다.

## 확인하지 못한 것

- 회차별 기출 빈도(수험 정리 글의 "자주 나온다"만 확인).
- 고국천왕 5부 개편·부자 상속·을파소 등용의 연도, 태조왕 대 계루부 왕위 세습 확립 시점.
- 무용총·강서대묘 벽화의 세부.
- 사료 원문 직접 대조 전부(한국사DB 원문 페이지는 이 세션에서 직접 열지 못했다).
