# 콘텐츠 사실 확인 체크리스트 (삼국, 스키마 v1)

`assets/data/cards/samguk.json` 44장을 사람이 확인할 때 쓴다. **위에서부터 순서대로** 본다. 확인한 카드는 JSON에서 `verified: true`, `verified_by: "이름 / 확인 자료 / 날짜"`로 바꾸고 `python3 tools/validate_cards.py`를 다시 돌린다.

참고: 독립 대조 보고서 `design/fact-check-report.md`(2차 자료 기준). 이 체크리스트는 그 보고서를 반영해 카드를 고친 뒤의 상태다(decision-log D25).

## 확인 방법

1. **핵심 사실**: 단서 3의 연도·인물·나라가 사료와 맞는가. 원문은 한국사데이터베이스(국사편찬위원회) 등에서 대조한다. 이 세션에서는 원문 사이트에 접속하지 못했다.
2. **시기 판단**: 해설이 D2 정의(건국기=건국 전승과 초창기, 전성기=확장과 번영, 결말기=전쟁의 마무리·멸망·통일 완성)와 맞는가. 갈리면 `disputed: true`와 `disputed_note`로 바꾸고 대체 카드를 넣는다(칸당 3장 유지).
3. **단서 1**: 이름·나라·시기를 뜻으로도 드러내지 않는가. 스크립트는 제목·나라 이름·시기 라벨만 기계적으로 검사한다.
4. **단서 2**: 기준 카드와의 연도 차이가 맞는가. 다른 나라 기준 카드를 언급할 때 주체가 헷갈리지 않는가.
5. **출처**: URL은 모두 null(지어낸 URL 없음). 메모의 '근거 미확인'·'원문 대조 필요'를 먼저 본다.
