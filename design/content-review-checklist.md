# 콘텐츠 사실 확인 체크리스트 (삼국, 스키마 v1)

`assets/data/cards/samguk.json`의 모든 카드를 사람이 확인할 때 쓴다. 확인을 마친 카드는 JSON에서 `verified: true`, `verified_by: "이름 / 확인 자료 / 날짜"`로 바꾸고 `python3 tools/validate_cards.py`를 다시 돌린다.

## 확인 방법

1. **핵심 사실**: 3단계 단서의 연도·인물·나라가 출처 사료와 맞는가. 원문은 한국사데이터베이스(국사편찬위원회) 등에서 직접 대조한다.
2. **시기 판단**: 해설의 근거가 D2 정의(건국기=건국 전승과 초창기, 전성기=확장과 번영, 결말기=전쟁의 마무리·멸망·통일 완성)와 맞는가. 판단이 갈리면 `disputed: true`로 바꾸고 `disputed_note`를 적는다.
3. **단서 1단계**: 이름·나라·시기를 드러내지 않는가(스크립트는 제목·나라 이름·시기 라벨만 기계적으로 검사한다).
4. **관계 단서**: 기준 카드와의 관계(연도 차이 등)가 맞는가. 예: '[황산벌 전투] 12년 전' → 660-648.
5. **출처**: `source.name`이 실제 사료이고 `note`의 불확실성 서술이 정확한가. URL은 모두 null이다(지어낸 URL 없음).
