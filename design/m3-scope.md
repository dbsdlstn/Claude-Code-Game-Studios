# 남북국 범위 초안: 통일신라·발해 (M2-A 이후 바로 시작할 수 있게)

> **상태**: 초안(2026-11-05, D132). 디렉터 요청 "M3 범위 초안". **번호 주의**: `docs/roadmap.md`는 남북국을 M4로, 백제·신라·가야를 M3로 두었다. 백제·신라·가야 콘텐츠(묶음 b1~b4)는 M2 안에서 이미 만들어지고 있어, 실질적으로 **남북국이 다음 콘텐츠 단계**다. 이 문서의 이름은 요청대로 `m3-scope`이고, 로드맵 갱신은 총괄이 정한다(제안: 12절).
> **근거**: `design/content-plan-m2.md`, `design/event-registry.md`, `design/gaya-timeline-model.md`, `design/exam-topics/silla.md`("문무왕 이후는 남북국 단계"), 로드맵 M4의 완료 조건 "두 나라가 같은 연표에 공존하는 표현이 사람 테스트로 확인".
> **콘텐츠 초안과의 정합(D133)**: 콘텐츠 세션이 `design/exam-topics/namguk.md`(D157: 통일신라 앵커 11, 발해 앵커 5, 2차 자료 검색 기반)를 올렸고 이 문서를 그에 맞췄다. nation 값(`usilla`·`balhae`), 등주 공격 소유(발해), 발해 앵커 5개의 관계 단서 폭, 경덕왕 녹읍 부활 연도 충돌을 아래 각 절에 반영했다.
> **한계**: 아래 왕·연도·사건은 **이 세션의 기억, 저장소의 기존 조사, 콘텐츠의 2차 자료 검색**에 기댄 후보이며 사료 원문으로 확인하지 않았다(특히 발해). 기출 빈도는 남북국에 대해 확인된 자료가 없다. 모든 연도는 **조사 대상**이다. 사실 확인 규칙(2인, 한국사DB, 기출 표기)은 그대로 적용된다.

## 2. 현황과 경계

- 기존 신라 덱(`silla-m2-b1~b4`)의 앵커는 박혁거세 ~ 문무왕(661)까지이고, 카드는 651 집사부, 660 백제 정벌, 675 매소성, 676 기벌포(삼국 통일 완성)까지다. 따라서 **문무왕 칸의 마지막 카드는 676**이다.
- 통일신라 덱은 **681(신문왕) 이후**를 맡고, 676 이전은 기존 덱 소유다(사건 목록의 한 사건 한 덱 규칙).
- 발해는 기존 덱이 없다(가야와 달리 왕계가 있고 한능검 출제도 독립 주제이므로 독립 덱이 맞다).

- **콘텐츠 안과 다른 점 2**: 이 문서의 이전 판은 선덕왕(780)을 뺐으나, 780년 혜공왕 피살과 하대 시작을 묻는 출제를 위해 **콘텐츠 안대로 앵커로 둔다**. 780년 사건은 선덕왕 즉위와 같은 해이므로 `answer.same_year: before_next_accession`(혜공왕 칸)을 쓴다. 이름은 `선덕왕(김양상)`으로 신라 덱의 선덕여왕(632)과 구별하고 id는 접두어(`usilla-`)로 분리된다.
- 문무왕(661)은 기존 신라 덱 앵커를 **참조**할 수 있다. 첫 칸 "문무왕 즉위 ~ 신문왕 즉위 전"에 카드가 없으면 참조도 필요 없다(콘텐츠: 신문왕에서 시작, 첫 칸 앞에 카드가 놓이지 않음).
- 왕 이름 표기와 즉위 연도는 한국사DB의 신라본기와 기출 표기로 확인해야 한다.

### 4.3 앵커 5개와 관계 단서(D68 2~3칸) 폭

콘텐츠가 짚은 문제: 발해 앵커가 5개뿐이라 D68의 "관계 단서는 후보 칸을 2~3개로 좁힌다"를 맞추면 단서가 거의 항상 "[A] 뒤, [C] 전"의 **두 칸**짜리가 되고, 문왕 칸(737~793, 57년)이 길며 선왕~대인선(818~906)이 비어 있다.

**검토 결과**:
1. **규칙은 맞출 수 있다.** 칸이 5개(고왕·무왕·문왕·선왕·대인선 칸)이고 관계 단서 "[앵커 k] 뒤, [앵커 m] 전"은 후보 칸 `m−k`개를 남긴다. 후보를 2개로 만드는 단서는 다음과 같다. 고왕 칸 → "[고왕] 뒤, [문왕] 전"(후보: 고왕·무왕 칸). 무왕 칸 → "[무왕] 뒤, [선왕] 전"(무왕·문왕 칸). 문왕 칸 → "[문왕] 뒤, [대인선] 전"(문왕·선왕 칸). 선왕 칸 → 같은 "[문왕] 뒤, [대인선] 전". 대인선 칸(마지막, 위가 열림) → "[선왕] 뒤"(선왕 이후 두 칸). 3칸이 필요하면 시작 앵커를 한 칸 앞당긴다. **검증기 V10a(후보 2~3칸)는 통과한다.** 단 선왕 칸과 문왕 칸 카드가 같은 단서를 쓸 수 있어 구별은 직접 단서가 맡는다.
2. **그러나 두 칸이면 단서가 "반반 확률"을 준다**: 다른 덱의 2~3칸/12칸(약 17~25%)과 달리 발해는 2칸/5칸(40%)이라 단서의 정보 비중이 크다. 단서를 열면 반은 맞힌다. 해법은 규칙을 바꾸는 것이 아니라 **인식하는 것**이다.
3. **찍기도 쉬워진다**: 시험의 "어느 왕 때인가"(`king_chosen`) 선택지가 **5명**이라 찍어서 맞힐 확률이 20%(다른 덱은 약 8%, 12명 기준)다. `rewards-spec.md` 7.2의 손익분기(찍기 `10p` 대 단서 `5q`, `q`=0.9 → `p=0.45`)에서 `p=0.2`는 여전히 단서가 유리하므로 보상 규칙은 그대로 둔다.
4. **카드가 많지 않은 덱이라 괜찮다**: 발해는 카드가 8~16장이라 단서의 정보 과다가 전체 학습에 주는 영향이 작다. M2 사람 테스트 T3(단서 행동)의 분석에서 발해를 따로 본다.
5. **앵커를 늘리는 대안**: 중간 왕(성왕·강왕·정왕·희왕·간왕 등)을 앵커로 더하면 폭이 넓어지지만, 즉위 연도 자료가 불확실하고 시험이 묻지 않아 확인 비용만 늘어난다. **권고: 5~7개 유지**(7개일 때 선왕 이전의 한 왕과 대인선 이전의 한 왕이 후보. 자료 확인 후 결정).

## 15. 스키마·표시 확장 (nation 값, 인장)

- **nation 값**: 콘텐츠 제안 `usilla`(통일신라)·`balhae`를 채택한다. 이유: 기존 `silla` 덱은 앵커 12가 이미 차 있어 같은 덱에 신문왕 이후를 이어 붙이면 앵커 상한(D85)을 넘는다. `design/card-data-schema-v2.md`의 V2 nation enum을 `goguryeo/baekje/silla/gaya` → **`goguryeo/baekje/silla/gaya/usilla/balhae`**로 확장한다(검증기와 웹 로더가 이 enum을 쓰는 곳 모두). id 패턴: 앵커 `usilla-reign-<slug>`, `balhae-reign-<slug>`, 사료 카드 `usilla-src-NN`, `balhae-src-NN`. `gaya`는 현재 카드가 없지만 enum에 남긴다(D96/D149).
- **표시 이름**: 나라 선택에서 "통일신라", "발해". 사건 목록 `participants`에도 같은 값을 쓴다.
- **인장·색**(`design/art/art-bible.md` 4.2는 4개국만 정의): 통일신라·발해의 인장 글자와 색이 필요하다. **통일신라는 `art-bible.md` 4.2에 확정**(D135: 인장 글자 "통", 색 `#5C3399`, 흰 글자 대비 8.79; 이전 임시값 `#7B4F8F`는 색각 이상에서 백제 청과 구별이 어려워 교체). 발해는 D183으로 보류이며 이전 제안의 먹회 `#44464F`도 백제 청과 가까워(ΔE 17~20) 쓰지 않는 쪽을 권고한다. 기존 값과 구별되도록 신라 금(`#C79A2E`, 등급 금과도 같은 색)을 피하고 백제 청·가야 녹청과 색상이 겹치지 않게 골랐다. 계산값이며 화면으로 확인하지 않았다.
- **경계 표시**: 연표 줄에서 통일신라 앵커 중 문무왕 이전의 칸은 신라 덱 소속임을 안내하지 않는다(통일신라 덱은 신문왕에서 시작하고 첫 칸 앞에 카드가 놓이지 않는다).
- **병행 연표 보기**(6절)는 두 덱의 앵커 `reign.start`만 읽으면 되므로 새 스키마 필드는 필요 없다.
