# UX 명세: 병행 연표 보기 (남북국: 통일신라 · 발해)

> **상태**: 초안(2026-11-05, D134). 디렉터 D181 채택안 "공존은 읽기 전용 병행 연표 보기, 꽂기는 나라별"의 화면 명세다. 남북국 카드 작성은 M2-A 웹 작업 뒤에 시작하므로(D181) **이 화면은 남북국 덱이 생길 때 만든다**. 지금은 명세만 있다.
> **근거**: `design/m3-scope.md` 6절, `design/ux/dogam.md`, `design/ux/title-screen.md`(나라 목록), `design/art/art-bible.md`(4.2·4.6), 결정 D182(발해 앵커 7개 = 독립 덱일 때), D200·D201(재위 확인 상태).
> **한계**: 시각 디자인은 아트 바이블 재정의 뒤다. 이 문서는 구조, 내용, 상호작용, 접근성, 수용 기준만 정한다. 앵커의 즉위·재위 연도는 콘텐츠 확인 상태(`design/exam-topics/namguk.md`)에 따라 바뀔 수 있다.

## 1. 목적과 원칙

- **목적**: 사용자가 "같은 시기에 신라는 누구 때였고 발해는 누구 때였는가"를 **한눈에 비교**한다. 시험에서 남북국을 묻는 비교 문항("(가) 시기 신라의…, 발해의…")을 돕는다.
- **읽기 전용**: 이 화면에서는 카드를 풀지 않고 꽂지 않는다. **학습 상태(상자, 일정)를 바꾸지 않고**, 보상(XP·업적)도 만들지 않는다.
- **정답을 알려 주지 않는다**: 아직 만나지 않은 카드의 연도와 위치는 보이지 않는다(점으로도 보이지 않는다). 연표의 앵커(왕)는 원래 공개 정보다.
- **일반화**: 2열 병행을 기본으로 하되, 같은 구조로 삼국(고구려·백제·신라)의 3열 병행 보기로 확장할 수 있게 쓴다(후속, 이 문서의 범위 밖).

## 2. 진입점

| 위치 | 조건 | 동작 |
|---|---|---|
| **타이틀 나라 목록**(`ux/title-screen.md` 4절)의 통일신라·발해 행 아래 | 두 덱이 모두 활성일 때만 | "남북국 병행 보기" 링크(44px 이상). 한 덱만 활성이면 링크가 안 보이고 도감에서만 안내 문구 |
| **숙련 도감 카드 탭 상단**(`ux/dogam.md` 3.1) | 선택한 나라가 통일신라 또는 발해일 때 | "병행 보기" 버튼(나란한 연표 아이콘 글자 "병행") |
| **카드 상세**(도감 3.3) | 카드가 통일신라 또는 발해일 때 | "같은 때 다른 나라는?" 링크 → 병행 보기가 그 카드의 연도로 스크롤되고 그 연도가 강조됨 |
| 결과 화면 | 없음 | 학습 흐름을 끊지 않는다 |

## 3. 화면 구조 (390px 세로, 전체 화면 시트)

세로 시간 축에 **두 열**(왼쪽 통일신라, 오른쪽 발해)을 나란히 둔다. 시간은 위에서 아래로 흐른다. 가로로 넘기는 구조는 쓰지 않는다(가로 스크롤 금지).

```
┌────────────────────────────┐
│ 남북국 병행 보기         [닫기] │  ← 머리글(고정)
│ [통일신라 ●]  [발해 ●]  연도 ▼ │  ← 열 머리(나라 인장) + 연도 점프
│                           │
│ 680 ┤                      │
│     │                      │
│     │ ┌신문왕 681~692─┐    │
│ 700 ┤ │               │ ┌고왕 698~719┐
│     │ ├성덕왕 702~737┤ │            │
│     │ │      ◆ 722    │ ├무왕 719~737┤
│ 750 ┤ │               │ ├문왕 737~793┤
│     │ ├경덕왕 742~765┤ │            │
│     │ ├혜공왕 765~780┤ │            │
│ 800 ┤ ├원성왕 785~798┤ ├강왕 794~809┤
│     │ …               │ …            │
│ 930 ┤ └경순왕 927~935┘ └대인선 ~926 ✕┘
│     │                      │
│ [목록으로 보기]               │  ← 접근성·대체 보기
└────────────────────────────┘
```

- **연도 축**: 가운데 또는 왼쪽 가장자리에 50년 단위 눈금과 숫자(`680`, `700`, `750`…). 눈금은 텍스트로도 읽힌다.
- **왕 칸(앵커)**: 해당 왕의 재위 구간을 **세로 블록**으로 그린다. 블록 안에 왕 이름과 재위("737~793"). 블록의 **위치와 높이는 재위 길이에 비례**(2.6px/년 제안, 680~940년 전체 약 676px)하고 **높이 최소 40px**이다. 최소 높이 때문에 이웃 블록과 겹치는 짧은 재위(선덕왕 780~785, 발해의 중간 왕)는 **위치 비례를 우선**하고 라벨만 열 바깥쪽으로 빼서 표시한다(눈금은 항상 정확). 탭하면 시트에 전체 정보가 나온다.
- **빈 구간**: 발해의 앵커가 없는 구간(독립 덱이 5개 앵커일 때 문왕 793~선왕 818 같은 구간)은 **빗금 띠 + "중간 왕들(연표에는 없음)"**로 표시한다. 비어 있는 것이 아니라 앵커가 없다는 뜻이다. 앵커 7개 안(D182: 강왕 794, 대이진 830 추가)에서는 이 구간이 짧아진다.
- **마지막 앵커의 끝**: 통일신라는 경순왕 935(귀부), 발해는 대인선 ~926(거란에 멸망)에서 끝나며 끝에 표시(✕ 또는 "멸망"/"귀부" 글자). 색만으로 구분하지 않는다.
- **나라 구분**: 열 머리와 블록 왼쪽 가장자리에 나라 인장(통일신라 "통", 발해 "발", `art-bible.md` 4.2 확장안)과 나라색 띠. 블록 안은 한지색 면.
- **만난 카드 점(◆)**: 사용자가 **이미 만난(도입된) 카드**만 연도 위치에 표시한다. 점 옆에 카드 제목(공개 후라 보여도 됨) 한 줄. 만나지 않은 카드는 **점도 없다**(위치가 정답 단서이므로).
- **강조**: 사용자가 왕 블록이나 점을 탭하면 시트가 열리고(4절), **그 시기와 겹치는 반대편 나라의 왕 블록이 강조**(테두리 굵게 + 배경 한 단계 진하게)된다. 강조는 색에만 의존하지 않고 테두리로도 구분한다.

## 4. 상호작용

| 동작 | 결과 |
|---|---|
| 왕 블록 탭 | **하단 시트**: 왕 이름, 재위(이설이 있으면 "이설: 392~413" 한 줄), 나라, 그 칸의 만난 카드 목록(제목·등급), "같은 때 다른 나라는: 경덕왕(742~765), 혜공왕(765~780)" 한 줄 |
| ◆(만난 카드) 탭 | 하단 시트: 카드 제목, 연도(`reign_label`), 해설 요약 두 줄 + [카드 상세] 링크(도감 카드 상세로 이동) |
| 연도 점프(▼) | 칩 목록: 700 · 750 · 800 · 850 · 900 → 해당 연도로 스크롤. 현재 보는 연도는 머리글 우측에 고정 표시("지금 보는 해: 약 770") |
| [닫기] | 병행 보기를 닫고 진입한 곳으로 복귀 |
| [목록으로 보기] | 접근성·대체 보기(6절) |

- 하단 시트에서 [카드 상세]를 누르면 병행 보기는 닫히지 않고 시트 아래에 남는다(돌아오면 스크롤 위치 유지).
- **학습 모드가 아닌 화면이므로** 단서, 연습, 정답 확인 버튼이 없다. 학습을 시작하려면 [닫기] 후 타이틀로 간다.

## 5. 데이터

- **읽는 것**: 두 덱의 앵커(`reign.start`, `reign.end`, `reign_alt`, 제목, 나라), 사용자가 만난 카드의 `year`·`title`·`reign_label`·해설 요약, 카드 등급(`leitner` 저장). 새 스키마 필드는 필요 없다.
- **재위 끝 연도**: 앵커 `reign.end`를 쓴다. 마지막 앵커의 끝은 멸망/귀부 연도(발해 926, 통일신라 935)로 둔다. `reign.end`가 없거나 다음 앵커의 `start`와 어긋나면(예: 발해 문왕 793 → 선왕 818) **간격을 빗금 띠로** 표시한다(위 "빈 구간").
- **이설**: `reign_alt`가 있으면 왕 블록에 작은 "이설" 글자를 붙이고 시트에서 설명한다(색에만 의존하지 않음). 블록 위치는 판정용 `reign`을 따른다.
- **계산**: 겹침(같은 때)은 두 재위 구간이 1년 이상 겹치는지로 계산하는 순수 함수(`overlapping(a, b)`). 연도 스케일은 `y = (year − 680) × 2.6`. 모든 값은 앵커 데이터에서 파생하며 하드코딩하지 않는다(첫 해와 마지막 해는 두 덱의 최소 start와 최대 end에서 계산).
- **저장**: 병행 보기는 저장하는 것이 없다(마지막 스크롤 위치도 저장하지 않는다).
- **덱 모양에 따른 분기**: 발해가 독립 덱(앵커 7개)이면 위처럼 7개 블록, **흡수 모델**(발해 카드가 통일신라 덱의 `tags: ["발해"]`로 있음)이면 발해 앵커가 없으므로 병행 보기를 만들지 않는다(진입 링크가 보이지 않는다).

## 6. 접근성

- **대체 보기 "목록으로 보기"**: 연도 구간을 50년 단위로 끊어 표로 보인다. 행: `700~749`, 열: 통일신라 · 발해. 셀에 그 구간에 걸치는 왕 이름과 재위를 쓴다. 스크린 리더와 큰 글꼴 사용자를 위한 **기본에 준하는 경로**이며, 시각 보기와 같은 정보를 담는다.
- 시각 보기: 각 왕 블록은 `button`, 이름은 "신문왕, 통일신라, 681년부터 692년까지"처럼 읽힌다. 점(◆)도 `button`("고구려"가 아닌 카드 제목, 연도). 열 머리는 `th`/`role="columnheader"` 의미를 갖는다.
- 키보드: Tab은 연도 점프 → 왼쪽 열 위에서 아래 → 오른쪽 열 위에서 아래 순서. 방향키 위/아래로 같은 열의 이웃 왕, 좌/우로 반대 열의 겹치는 왕으로 이동할 수 있게 한다(선택).
- 터치 목표: 블록과 점 **44px 이상**(짧은 왕 블록은 최소 높이 40px + 라벨 영역 탭으로 44px 확보). 점이 겹쳐 눌리기 어려우면 **해당 연도의 점 묶음**("3장")을 하나의 버튼으로 합치고 탭하면 시트에 목록을 보인다.
- 색: 나라색은 장식이고 뜻은 열 머리·인장 글자·텍스트가 전한다. 강조는 테두리로도 구분.
- `prefers-reduced-motion`: 스크롤 애니메이션과 시트 모션 없음(즉시 전환).
- 글자 크기: 왕 이름 16px, 재위·보조 12px 이상. 큰 글꼴 설정에서는 왕 이름만 남기고 재위는 시트로 옮긴다.
- 가로 스크롤 없음. 너비 390px에서 각 열 약 165px, 가운데 눈금 40px.

## 7. 상태와 예외

| 상태 | 처리 |
|---|---|
| 한 덱만 활성 | 병행 보기 진입점이 없다. 도감에서 직접 열려 하면 "통일신라와 발해가 모두 열려야 볼 수 있어요" 안내 |
| 만난 카드가 없음 | 왕 블록만 보이고 점이 없다. 상단에 "카드를 만나면 이 연표에 표시돼요" 한 줄 |
| 앵커 `reign.end` 누락/불일치 | 빗금 띠, 시트에는 "자료 없음"을 쓰지 않고 "연표에는 없는 시기" |
| 이설이 있는 왕 | 작은 "이설" 글자와 시트의 한 줄 설명(블록 위치는 `reign` 기준) |
| 데이터 로딩 | 버튼 비활성, "불러오는 중" 텍스트(스피너 없음) |
| 사람 테스트 모드(`?study=1`) | 이 화면은 열리지 않는다(도감과 같음) |
| 아직 확인되지 않은 재위(콘텐츠 `확인` 표시가 '기억') | 학습자에게는 구분해서 보이지 않는다(카드와 같은 verified 게이트로 처리: 확인 전 앵커는 release에서 빠지고 연표도 없다) |

## 8. 로그(선택, 사람 테스트용 제안)

`m2-plan.md`/남북국 단계 테스트에서 쓸 이벤트: `parallel_open`(진입점 `from`), `parallel_tap_king`(`anchor_id`), `parallel_tap_card`(`card_id`), `parallel_list_view`(목록으로 보기 사용), `parallel_close`(`dwell_ms`). 자유 입력은 없다.

## 9. 수용 기준

1. 통일신라와 발해가 모두 활성일 때만 진입점이 보인다(타이틀 나라 목록, 도감, 카드 상세의 "같은 때 다른 나라는?").
2. 두 열이 세로 시간 축을 공유하고 50년 눈금이 있다. 390px에서 가로 스크롤이 없다.
3. 왕 블록의 위치·높이가 `reign.start`/`reign.end`와 일치한다(2.6px/년 비례, 최소 높이 40px). 눈금이 정확하다(블록 최소 높이 때문에 라벨만 옆으로 옮겨도 눈금은 비례).
4. 앵커가 없는 구간은 빗금 띠 "연표에는 없는 시기"로 표시된다(발해 앵커 5개 안에서 문왕~선왕 구간).
5. 사용자가 만난 카드만 점으로 표시되고, 만나지 않은 카드는 점도 제목도 없다(위치 단서 없음).
6. 왕 블록을 탭하면 시트에 재위(이설 포함), 그 칸의 만난 카드, "같은 때 다른 나라는" 한 줄이 보이고 반대편 겹치는 왕 블록이 테두리로 강조된다. 겹침 계산이 1년 이상 겹침 기준이다.
7. "목록으로 보기"가 50년 단위 표로 같은 정보를 제공한다. 스크린 리더로 왕 블록이 "이름, 나라, 재위"로 읽힌다.
8. 이 화면은 학습 상태, 보상, 로그의 인출 줄을 바꾸지 않는다. `?study=1`에서는 열리지 않는다.
9. 점이 많은 연도는 묶음 버튼으로 합쳐지고 모든 터치 목표가 44px 이상이다.
10. 발해가 흡수 모델이면 진입점이 나타나지 않는다.

## 10. 열린 질문
- 짧은 재위(선덕왕 780~785, 발해의 중간 왕)를 블록 대신 얇은 선으로 표현할지.
- 삼국(고구려·백제·신라) 3열 병행 보기를 같은 구조로 확장할지(열 폭 약 110px로 왕 이름이 잘릴 수 있음).
- 연도 축이 세로 길이 676px로 한 화면을 넘는 것이 좋은지(가로 스크롤 없이 연도 점프로 해결). 화면 높이 안에 모두 넣는 압축 보기를 따로 둘지.
