# UX 명세: 세션 결과 화면의 보상 연출과 문구 (M2)

> **상태**: 초안(2026-11-05, D94 후속 → D122) → **보상 평가 반영 개정(D98: 한 화면 구조 D165, 바뀐 카드만, 첫 승급 +5 삭제 D164, 해제 만회 +5 D166; D128)**. 일반 학습 모드 전용이다. `?study=1`(사람 테스트)에는 보상이 없고 기존 결과 화면(정답 수, 다시 풀기, 다음 세션 복습 수)만 쓴다.
> **근거**: `design/rewards-spec.md` §1·§3~§6·§14, `design/leitner-spec.md`, `design/ux/title-screen.md`, 웹 골격 D82의 결과 화면(`#summary`).
> **원칙**: 보상은 **학습 결과 뒤에** 보인다(결과 요약이 먼저). 짧고, 건너뛸 수 있고, 꾸짖지 않는다. 문구는 해요체, 한 줄 20자 안팎.
> **한계**: 시각 연출(색, 모션 곡선, 효과음)은 아트 바이블 재정의 후이고 이 문서는 순서, 내용, 문구, 접근성만 정한다.

## 1. 목적과 구조 (한 화면, D165)

**평가에서 나온 문제**(`docs/reviews/evaluation-rewards.md`): 결과 화면이 단계마다 "계속"을 눌러야 해서 첫 세션 5번, 이후 3번 탭이 든다. 매일 반복하면 "건너뛰기"가 습관이 되어 6단계의 의미가 사라진다. 또 사람이 보고 싶은 것은 **바뀐 것**이고, **다음 복습이 맨 끝**에 있어 다음 세션 동기가 약하다.

그래서 결과는 **탭 없이 한 화면(한 번 스크롤)**이다. 위에서 아래로 **자동으로 차례로 나타나며**(총 약 3~4초), 화면 아무 곳이나 탭하면 애니메이션이 끝나고 최종 상태가 한꺼번에 보인다. 사용자는 아무것도 누르지 않아도 모든 것을 볼 수 있다(자동 진행에 쓰는 시간은 읽기 속도를 방해하지 않도록 각 줄이 나타난 뒤 사라지지 않고 쌓인다).

```
[A 결과 요약]  정답 5 / 7
[B 다음 복습]  다음 세션 복습 6장            [ 다음 세션 ]  ← 맨 위 가까이
[C 이번 세션]  +47 XP  (상한이 걸리면 "오늘 경험치는 다 모았어요")
[D 바뀐 카드]  상자·등급이 바뀐 카드만 (+XP와 이유)   [그 밖에 n장은 변화 없어요 · 전체 보기]
[E 하루 목표·연속일]  (해당 시)
[F 레벨]  (해당 시는 레벨업, 아니면 XP 막대만)
[G 업적]  (새 업적이 있을 때만, 최대 3개 + "그 밖에 n개")
```

- 사건이 없는 블록은 생략한다(예: 새 업적이 없으면 G 없음).
- `prefers-reduced-motion`이면 처음부터 모든 블록이 정적으로 보인다.
- **[다음 세션] 버튼은 B 블록에 있다**(화면을 끝까지 내리지 않아도 보인다). 하단 고정 버튼 줄에는 [숙련 도감][타이틀로]만 둔다.

## 2. 블록별 내용과 문구

### 2.1 A 결과 요약 (항상)
| 요소 | 내용 |
|---|---|
| 제목 | "오늘의 세션" (나라 표시: "고구려") |
| 큰 숫자 | "정답 5 / 7" |
| 보조 줄 | "깨끗한 정답 4 · 단서를 쓴 정답 1 · 오답 2" |
| 재도전 | "다시 풀기 2장 중 1장 성공" (재도전이 있었을 때) |

보상 XP는 이 블록에서 **보이지 않는다**(학습 결과가 보상에 가려지지 않게). **머리글의 세션 번호는 방금 끝난 세션을 가리킨다**("세션 2" 완료 화면에서 다음 번호 "세션 3"으로 바뀌어 보이면 안 된다; 평가에서 발견한 오류).

### 2.2 B·C·D 블록: 다음 복습, 이번 세션 XP, 바뀐 카드

**B 다음 복습**
| 상황 | 문구 |
|---|---|
| 다음 세션에 도래한 카드가 있음 | "다음 세션 복습 n장" + [다음 세션] |
| 없음 | "다음 세션에는 새 카드부터 시작해요" + [다음 세션] |
| 신규 도입이 멈춘 상태(백로그 보호) | "아직 열리지 않은 카드 n장 · 복습을 먼저 마치면 열려요" |
| 오늘 목표 달성 + 권장 상한 근처 | "오늘은 충분히 했어요. 내일 이어서 해요" ([다음 세션]은 보조 스타일) |

도래·새 카드가 모두 없으면 [다음 세션]은 "오늘은 여기까지"로 바뀌고 비활성이다. 틀린 카드가 있으면 "다음 세션 복습"에 그 카드가 들어간다(평가에서 지적된 "틀렸는데 새 카드부터라고 말함" 오류는 학습 쪽 결함 D163이 고친 뒤에야 의미가 있다).

**C 이번 세션 XP**
| 상황 | 문구 |
|---|---|
| 평상시 | "이번 세션 +47 XP" |
| 하루 2세션을 넘긴 세션 | **"오늘 경험치는 다 모았어요 (하루 두 세션까지)"** 한 줄. 카드별 "+0" 줄은 쓰지 않는다. 승급·등급 보너스가 있으면 그 합만 "+10 XP" 로 따로 쓴다 |

**D 바뀐 카드만** (평가: 사람이 실제로 보고 싶은 것은 바뀐 것)
보이는 카드: **상자나 등급이 바뀐 카드** — 승급, 강등, 재학습 표시가 새로 붙은 오답, 재학습 해제, 동·은·금 달성. 줄 형식: `제목 · 결과 · +XP`.

| 결과 | 문구 | XP |
|---|---|---|
| 깨끗한 정답 | "깨끗한 정답" | +10 |
| 관계 단서 후 정답 | "단서를 보고 맞힘" | +5 |
| 직접 단서 후 정답 | "직접 단서를 보고 맞힘" | +3 |
| 오답 | "해설을 읽어 보세요" | +0 |

- **승급** 줄(상자 2 이상에서만 XP): "상자 2 → 3 · +5". **상자 1 → 2**는 "상자 1 → 2"만 보이고 보너스 줄은 없다(D164).
- **재학습 해제**(D166): "지난번 틀린 카드를 이겨 냈어요 · +5" 한 줄과 "상자 1 → 2".
- **재학습 표시가 새로 붙은 카드**: "다음에 두 번 연속 맞히면 올라가요".
- **등급** 줄: "동 등급이 되었어요 · +20" / "은 등급 · +40" / "금 등급 · +80".
- 단서를 쓴 카드에는 작은 보조 문구 "깨끗하게 맞히면 +10"(강요하지 않는 정보, 오답 카드에는 없음, 화면당 한 번만 문구를 쓰고 같은 줄은 반복하지 않는다).
- **바뀌지 않은 카드**(상자와 등급이 그대로): "그 밖에 n장은 변화 없어요" 한 줄로 접고 [전체 보기]로 펼치면 `제목 · 결과 · +XP` 전체 목록. 바뀐 카드가 6장을 넘으면 처음 5장 + "더 보기".

### 2.3 E 하루 목표와 연속일 (해당 시)
| 상황 | 문구 |
|---|---|
| 오늘 첫 목표 달성 | "오늘 목표 달성 · +20" |
| 연속일 증가 | "연속 3일째예요" |
| 휴식권 사용 | "쉬는 날 보호권을 하나 썼어요. 연속 7일이 이어졌어요" |
| 휴식권 획득(연속 7일마다) | "쉬는 날 보호권을 얻었어요 (2장까지 모아요)" |
| 연속이 끊긴 뒤 첫 학습 | "다시 오셨네요. 최고 연속 12일 · 오늘부터 1일째" (꾸짖지 않는다) |
| 이미 목표를 채운 날의 추가 세션 | (표시 없음) |

### 2.4 F 레벨 (레벨이 오를 때만)
| 상황 | 문구 |
|---|---|
| 레벨업 | "레벨 6이 되었어요" + XP 막대 |
| 칭호 변경(레벨 5·10·15·20·30·40) | "새 칭호: 서당 학동" + "칭호는 도감에서 바꿀 수 있어요" |
| 여러 레벨이 한꺼번에 오름 | 마지막 레벨만 표시: "레벨 4 → 6" |
| 레벨업 없음 | XP 막대만(현재 레벨, 다음 레벨까지 n XP) |

### 2.5 G 업적 (새로 달성한 것만, 최대 3개 먼저)
형식: `업적 · 이름` + 한 줄 설명. 여러 개면 처음 3개를 보이고 "그 밖에 n개"로 접는다(도감에서 확인).

| 업적 | 문구 |
|---|---|
| 첫 걸음 | "첫 걸음 · 첫 세션을 마쳤어요" |
| 첫 동 | "첫 동 · 카드 하나가 동 등급이 되었어요" |
| 첫 은 | "첫 은 · 카드 하나가 은 등급이 되었어요" |
| 첫 금 | "첫 금 · 카드 하나를 금 등급까지 올렸어요" |
| 깨끗한 한 판 | "깨끗한 한 판 · 한 세션에서 5장을 모두 힌트 없이 맞혔어요" |
| 오답 노트 비우기 | "오답 노트 비우기 · 틀렸던 카드를 모두 다시 익혔어요" |
| 사흘 연속 | "사흘 연속 · 3일 이어서 공부했어요" |
| 일주일 연속 | "일주일 연속 · 7일 이어서 공부했어요" |
| 한 달 연속 | "한 달 연속 · 30일 이어서 공부했어요" |
| 열흘의 공부 | "열흘의 공부 · 공부한 날이 10일이 되었어요" |
| 쉰 날의 공부 | "쉰 날의 공부 · 공부한 날이 50일이 되었어요" |
| 다시 오셨네요 | "다시 오셨네요 · 쉬었다가 돌아와 공부했어요" |
| 왕대 하나 은 | "왕대 하나 은 · {왕} 때의 카드를 모두 은 등급 이상으로 올렸어요" |
| (나라별) 연표 도입 완료 | "{나라} 연표 도입 완료 · 모든 카드를 한 번씩 만났어요" |
| (나라별) 동 완성 | "{나라} 동 완성 · 모든 카드가 동 등급 이상이에요" |
| (나라별) 은 완성 | "{나라} 은 완성 · 모든 카드가 은 등급 이상이에요" |
| (나라별) 금 완성 | "{나라} 금 완성 · 모든 카드가 금 등급이에요" |

업적 달성에는 XP가 없다(`rewards-spec.md` §4).

## 3. 레이아웃 (390px 세로)

- 시트는 화면 높이의 약 90%, 안쪽에서 스크롤한다. **A 결과 요약과 B 다음 복습([다음 세션] 버튼 포함)은 스크롤 없이 첫 화면에 보인다.**
- 블록은 위에서 아래로 쌓이고 새 블록이 나타나도 시트가 자동으로 스크롤하지 않는다(사용자가 읽던 위치를 잃지 않게; 한 번 스크롤해 아래를 본다).
- 하단 고정 버튼 줄은 [숙련 도감][타이틀로]. [다음 세션]은 B 블록에 있다. 터치 목표 44px 이상, 간격 8px 이상.
- 한 줄 문구는 줄바꿈을 허용하고 글자 크기는 16px(보조는 12px 이상).

```
┌────────────────────────────┐
│ 오늘의 세션 · 고구려 · 세션 2   │
│        정답 5 / 7           │
│ 깨끗한 정답 4 · 단서 1 · 오답 2│
│────────────────────────────│
│ 다음 세션 복습 6장            │
│ [   다음 세션   ]            │  ← 첫 화면 안
│────────────────────────────│
│ 이번 세션 +47 XP              │
│ 바뀐 카드                     │
│ 평양 천도  깨끗한 정답   +10   │
│   상자 2 → 3 · +5            │
│ 진대법  지난번 틀린 카드를 이겨 │
│   냈어요 · +5  (상자 1 → 2)  │
│ 그 밖에 3장은 변화 없어요 ▾   │
│────────────────────────────│
│ 오늘 목표 달성 · +20          │
│ 연속 3일째예요               │
│ 레벨 6이 되었어요  ▓▓▓░░      │
│ 업적 · 첫 걸음               │
│────────────────────────────│
│ [숙련 도감]   [타이틀로]       │
└────────────────────────────┘
```

## 4. 접근성

- 결과 영역은 `role="dialog"`(기존)이고, 블록이 나타날 때마다 **`aria-live="polite"` 영역에 한 줄 요약**을 알린다(예: "레벨 6이 되었어요. 새 칭호 서당 학동"). 화면을 탭해 애니메이션을 끝내면 최종 요약을 한 번 읽는다. 스크린 리더 사용 시에는 애니메이션 없이 정적으로 시작한다.
- XP 막대는 `role="progressbar"` + `aria-valuenow/min/max`와 텍스트("72 / 145 XP").
- 색만으로 상태를 전하지 않는다(승급은 화살표 글자, 등급은 "동/은/금" 글자).
- 키보드: 열리면 [다음 세션]에 포커스, Enter/Space로 실행, 애니메이션은 아무 키로 끝낼 수 있다, Esc는 **무시**한다(실수로 닫아 보상 정산을 놓치지 않게. 닫기는 [타이틀로]나 [다음 세션] 버튼으로만).
- `prefers-reduced-motion`: 애니메이션 없음, 모든 블록 정적(§1).
- 번쩍임: 초당 3회 이상 깜빡이는 효과 금지.
- 효과음은 기본 꺼짐(후속), 켜져도 레벨업·업적에만.

## 5. 상태와 예외

| 상태 | 처리 |
|---|---|
| 연습 세션(미리 복습·오답 노트) | 결과 요약만. 보상 블록 없음, 상단에 "연습이라 기록은 바뀌지 않아요" |
| 보상이 꺼진 설정/테스트 모드 | 기존 결과 화면(2.1, 2.6) |
| 저장 실패 | "기록을 저장하지 못했어요. 이 화면을 닫기 전에 다시 시도하세요" + [다시 시도]. 보상 표시는 하되 저장되지 않았음을 알린다 |
| 세션 도중 앱 종료 후 복귀 | 다음 실행에서 끝난 세션으로 처리(Leitner 규칙), 보상 정산은 한 번만(중복 정산 방지: 세션 id로 멱등) |
| 카드 0장(빈 세션) | 결과 화면 없음(기존 "다음 세션으로" 화면) |
| 업적이 많이 한꺼번에 | 3개 + "그 밖에 n개" |

## 6. 데이터
읽는 것: 세션 결과(카드별 결과, 상자 전후, 등급 전후), 보상 저장(`rewards-spec.md` §10), 도감 설명 문구. 쓰는 것: 보상 상태(XP, 레벨, 연속, 업적)는 세션 종료 시 **한 번** 정산(멱등). 정산 함수는 순수 함수(날짜 주입).

## 7. 수용 기준
1. 결과 화면에 탭 없이 모든 블록이 나타난다(필요한 탭 0번). 화면을 탭하면 애니메이션이 끝나고 최종 상태가 보인다. `prefers-reduced-motion`이면 처음부터 정적이다.
2. A 결과 요약과 B 다음 복습, [다음 세션] 버튼이 스크롤 없이 첫 화면에 보이고 A에는 XP가 없다. 머리글의 세션 번호는 방금 끝난 세션이다.
3. D 블록에는 **상자나 등급이 바뀐 카드만** 있고, 나머지는 "그 밖에 n장은 변화 없어요"로 접히며 [전체 보기]로 전체 목록(결과와 +XP)이 보인다.
4. XP 문구가 `10 > 5 > 3 > 0`과 같은 순서다: 깨끗한 정답 +10, 단서 +5, 직접 단서 +3, 오답 +0. 용어는 "직접 단서"이고 "직접 힌트"가 없다.
5. 상자 1 → 2(처음 보는 카드의 첫 정답 포함)에는 승급 보너스 줄이 없고, 상자 2 이상 승급에는 "+5" 줄이 있다. 재학습 해제에는 "지난번 틀린 카드를 이겨 냈어요 · +5"가 나온다.
6. 하루 2세션을 넘긴 세션은 카드별 "+0" 줄 없이 "오늘 경험치는 다 모았어요" 한 줄이고, 승급·등급·만회 보너스가 있으면 그 합이 따로 보인다.
7. 레벨업이 없으면 레벨 블록은 막대만, 있으면 새 레벨(여러 단계는 "n → m")과 칭호 변경 시 새 칭호가 보인다. 새 업적이 없으면 G가 없고 4개 이상이면 3개 + "그 밖에 n개".
8. 같은 세션을 두 번 정산하지 않는다(멱등). 연습·테스트 모드에서는 보상 블록이 없다.
9. 390px 폭에서 가로 스크롤이 없고 모든 버튼이 44px 이상이다.
10. 틀린 카드가 있으면 B의 "다음 세션 복습"에 그 카드가 포함된다(학습 쪽 D163이 선행).

## 8. 열린 질문
- 자동 진행 옵션과 효과음(후속).
- 카드별 정산이 많은 세션(8장)에서 너무 길지 않은지(사람 반응).
- 업적 문구의 말투를 아트·내러티브와 맞출지(이 문서는 해요체 임시안).
- "깨끗하게 맞히면 +10" 보조 문구가 단서를 막는 압박으로 읽히는지.
