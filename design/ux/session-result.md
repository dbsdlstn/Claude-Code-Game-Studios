# UX 명세: 세션 결과 화면의 보상 연출과 문구 (M2)

> **상태**: 초안(2026-11-05, D94 후속 → D122). 일반 학습 모드 전용이다. `?study=1`(사람 테스트)에는 보상이 없고 기존 결과 화면(정답 수, 다시 풀기, 다음 세션 복습 수)만 쓴다.
> **근거**: `design/rewards-spec.md` §1·§3~§6·§14, `design/leitner-spec.md`, `design/ux/title-screen.md`, 웹 골격 D82의 결과 화면(`#summary`).
> **원칙**: 보상은 **학습 결과 뒤에** 보인다(결과 요약이 먼저). 짧고, 건너뛸 수 있고, 꾸짖지 않는다. 문구는 해요체, 한 줄 20자 안팎.
> **한계**: 시각 연출(색, 모션 곡선, 효과음)은 아트 바이블 재정의 후이고 이 문서는 순서, 내용, 문구, 접근성만 정한다.

## 1. 목적과 흐름

세션이 끝나면 한 화면(시트)에서 위에서 아래로 6단계가 이어진다. 사용자는 **언제든 "건너뛰기"**로 최종 상태(모든 단계가 한 번에 보이는 정적 요약)로 갈 수 있다.

```
[1 결과 요약] → [2 카드별 정산] → [3 하루 목표·연속일] → [4 레벨] → [5 업적·칭호] → [6 다음 복습]
        ↑ 처음부터 보임                      ↓ 각 단계는 해당 사건이 있을 때만 나타남
```

- 사건이 없는 단계는 생략한다(예: 새 업적이 없으면 5단계 없음).
- 총 연출 시간은 **약 4~6초 이내**(건너뛰기 없이 끝까지 볼 때). 모든 단계는 사용자가 읽는 속도에 맞춰 **자동으로 넘기지 않고**, 탭하면 다음 단계로 가거나 "건너뛰기"로 최종 상태에 간다(자동 진행은 접근성에 불리). 기본은 탭 진행, 설정에서 "자동 진행"을 켤 수 있게 하는 것은 후속.
- `prefers-reduced-motion`이면 애니메이션 없이 **모든 단계가 한 번에 정적으로** 보인다.

## 2. 단계별 내용과 문구

### 2.1 결과 요약 (항상)
| 요소 | 내용 |
|---|---|
| 제목 | "오늘의 세션" (나라 표시: "고구려") |
| 큰 숫자 | "정답 5 / 7" |
| 보조 줄 | "깨끗한 정답 4 · 단서를 쓴 정답 1 · 오답 2" |
| 재도전 | "다시 풀기 2장 중 1장 성공" (재도전이 있었을 때) |

보상 XP는 이 단계에서 **보이지 않는다**(학습 결과가 보상에 가려지지 않게).

### 2.2 카드별 정산 (카드가 1장 이상일 때)
카드마다 한 줄: `제목 · 결과 · +XP`. 카드 제목은 정답 공개 후이므로 보여도 된다.

| 결과 | 문구 | XP |
|---|---|---|
| 깨끗한 정답 | "깨끗한 정답" | +10 |
| 관계 단서 후 정답 | "단서를 보고 맞힘" | +5 |
| 직접 단서 후 정답 | "직접 힌트를 보고 맞힘" | +3 |
| 오답 | "해설을 읽어 보세요" | +0 |

- **승급** 줄(해당 카드): "상자 2 → 3 · +5". **등급** 줄: "동 등급이 되었어요 · +20" / "은 등급 · +40" / "금 등급 · +80".
- 단서를 쓴 카드에는 작은 보조 문구: "깨끗하게 맞히면 +10" (강요하지 않는 정보, 오답 카드에는 표시하지 않는다).
- **재학습 표시가 붙은 카드**(상자 1에서 오답): "다음에 두 번 연속 맞히면 올라가요" 한 줄.
- 카드가 많으면 처음 5장만 보이고 "더 보기"로 펼친다.
- 합계 줄: "이번 세션 +N XP".

### 2.3 하루 목표와 연속일 (해당 시)
| 상황 | 문구 |
|---|---|
| 오늘 첫 목표 달성 | "오늘 목표 달성 · +20" |
| 연속일 증가 | "연속 3일째예요" |
| 휴식권 사용 | "쉬는 날 보호권을 하나 썼어요. 연속 7일이 이어졌어요" |
| 휴식권 획득(연속 7일마다) | "쉬는 날 보호권을 얻었어요 (2장까지 모아요)" |
| 연속이 끊긴 뒤 첫 학습 | "다시 오셨네요. 최고 연속 12일 · 오늘부터 1일째" (꾸짖지 않는다) |
| 이미 목표를 채운 날의 추가 세션 | (표시 없음) |

### 2.4 레벨 (레벨이 오를 때만)
| 상황 | 문구 |
|---|---|
| 레벨업 | "레벨 6이 되었어요" + XP 막대 |
| 칭호 변경(레벨 5·10·15·20·30·40) | "새 칭호: 서당 학동" + "칭호는 도감에서 바꿀 수 있어요" |
| 여러 레벨이 한꺼번에 오름 | 마지막 레벨만 표시: "레벨 4 → 6" |
| 레벨업 없음 | XP 막대만(현재 레벨, 다음 레벨까지 n XP) |

### 2.5 업적 (새로 달성한 것만, 최대 3개 먼저)
형식: `업적 · 이름` + 한 줄 설명. 여러 개면 처음 3개를 보이고 "그 밖에 n개"로 접는다(도감에서 확인).

| 업적 | 문구 |
|---|---|
| 첫 걸음 | "첫 걸음 · 첫 세션을 마쳤어요" |
| 첫 동 | "첫 동 · 카드 하나가 동 등급이 되었어요" |
| 첫 은 | "첫 은 · 카드 하나가 은 등급이 되었어요" |
| 첫 금 | "첫 금 · 카드 하나를 금 등급까지 올렸어요" |
| 깨끗한 한 판 | "깨끗한 한 판 · 한 세션에서 5장을 모두 힌트 없이 맞혔어요" |
| 오답 노트 비우기 | "오답 노트 비우기 · 틀렸던 카드를 모두 다시 익혔어요" |
| 사흘 연속 | "사흘 연속 · 3일 이어서 공부했어요" |
| 일주일 연속 | "일주일 연속 · 7일 이어서 공부했어요" |
| 한 달 연속 | "한 달 연속 · 30일 이어서 공부했어요" |
| 열흘의 공부 | "열흘의 공부 · 공부한 날이 10일이 되었어요" |
| 쉰 날의 공부 | "쉰 날의 공부 · 공부한 날이 50일이 되었어요" |
| 다시 오셨네요 | "다시 오셨네요 · 쉬었다가 돌아와 공부했어요" |
| 왕대 하나 은 | "왕대 하나 은 · {왕} 때의 카드를 모두 은 등급 이상으로 올렸어요" |
| (나라별) 연표 도입 완료 | "{나라} 연표 도입 완료 · 모든 카드를 한 번씩 만났어요" |
| (나라별) 동 완성 | "{나라} 동 완성 · 모든 카드가 동 등급 이상이에요" |
| (나라별) 은 완성 | "{나라} 은 완성 · 모든 카드가 은 등급 이상이에요" |
| (나라별) 금 완성 | "{나라} 금 완성 · 모든 카드가 금 등급이에요" |

업적 달성에는 XP가 없다(`rewards-spec.md` §4).

### 2.6 다음 복습 (항상)
| 상황 | 문구 |
|---|---|
| 다음 세션에 도래한 카드가 있음 | "다음 세션 복습 n장" |
| 없음 | "다음 세션에는 새 카드부터 시작해요" |
| 신규 도입이 멈춘 상태(백로그 보호, `rewards-spec.md` §14) | "아직 열리지 않은 카드 n장 · 복습을 먼저 마치면 열려요" |
| 오늘 목표 달성 + 권장 상한 근처 | "오늘은 충분히 했어요. 내일 이어서 해요" |
| 이미 하루 2세션을 넘겨 XP가 없는 세션 | "경험치는 하루 두 세션까지예요. 학습은 그대로 쌓여요" |

버튼: **[다음 세션]**(주, 도래/새 카드가 있을 때만 활성), [숙련 도감], [타이틀로]. 도래·새 카드가 없으면 [다음 세션]은 "오늘은 여기까지"로 바뀌고 비활성이다.

## 3. 레이아웃 (390px 세로)

- 시트는 화면 높이의 약 90%, 안쪽에서 스크롤한다. **결과 요약(2.1)은 항상 첫 화면(스크롤 없이)에 보인다.**
- 단계는 위에서 아래로 쌓이고, 새 단계가 나타나면 시트가 그 단계까지 스크롤한다(이전 단계는 유지).
- 아래에 고정된 버튼 줄(건너뛰기 → 마지막에는 [다음 세션][숙련 도감][타이틀로]). 터치 목표 44px 이상, 간격 8px 이상.
- 한 줄 문구는 줄바꿈을 허용하고 글자 크기는 16px(보조는 12px 이상).

```
┌────────────────────────────┐
│ 오늘의 세션 · 고구려          │
│        정답 5 / 7           │
│ 깨끗한 정답 4 · 단서 1 · 오답 2│
│────────────────────────────│
│ 카드별 정산                  │
│ 평양 천도   깨끗한 정답   +10 │
│   상자 2 → 3 · +5          │
│ 살수대첩   단서를 보고 맞힘 +5 │
│   깨끗하게 맞히면 +10        │
│ …            [더 보기]       │
│ 이번 세션 +47 XP            │
│────────────────────────────│
│ 오늘 목표 달성 · +20          │
│ 연속 3일째예요               │
│────────────────────────────│
│ 레벨 6이 되었어요  ▓▓▓▓░░    │
│ 새 칭호: 서당 학동            │
│────────────────────────────│
│ 업적 · 첫 걸음               │
│────────────────────────────│
│ 다음 세션 복습 6장            │
│ [건너뛰기]  →  [다음 세션]    │
└────────────────────────────┘
```

## 4. 접근성

- 결과 영역은 `role="dialog"`(기존)이고, 단계가 나타날 때마다 **`aria-live="polite"` 영역에 한 줄 요약**을 알린다(예: "레벨 6이 되었어요. 새 칭호 서당 학동"). 건너뛰기 후에는 최종 요약을 한 번 읽는다.
- XP 막대는 `role="progressbar"` + `aria-valuenow/min/max`와 텍스트("72 / 115 XP").
- 색만으로 상태를 전하지 않는다(승급은 화살표 글자, 등급은 "동/은/금" 글자).
- 키보드: 열리면 [건너뛰기]에 포커스, Enter/Space로 다음 단계, Esc는 **무시**한다(실수로 닫아 보상 정산을 놓치지 않게. 닫기는 [타이틀로]나 [다음 세션] 버튼으로만).
- `prefers-reduced-motion`: 애니메이션 없음, 모든 단계 정적(§1).
- 번쩍임: 초당 3회 이상 깜빡이는 효과 금지.
- 효과음은 기본 꺼짐(후속), 켜져도 레벨업·업적에만.

## 5. 상태와 예외

| 상태 | 처리 |
|---|---|
| 연습 세션(미리 복습·오답 노트) | 결과 요약만. 보상 단계 없음, 상단에 "연습이라 기록은 바뀌지 않아요" |
| 보상이 꺼진 설정/테스트 모드 | 기존 결과 화면(2.1, 2.6) |
| 저장 실패 | "기록을 저장하지 못했어요. 이 화면을 닫기 전에 다시 시도하세요" + [다시 시도]. 보상 표시는 하되 저장되지 않았음을 알린다 |
| 세션 도중 앱 종료 후 복귀 | 다음 실행에서 끝난 세션으로 처리(Leitner 규칙), 보상 정산은 한 번만(중복 정산 방지: 세션 id로 멱등) |
| 카드 0장(빈 세션) | 결과 화면 없음(기존 "다음 세션으로" 화면) |
| 업적이 많이 한꺼번에 | 3개 + "그 밖에 n개" |

## 6. 데이터
읽는 것: 세션 결과(카드별 결과, 상자 전후, 등급 전후), 보상 저장(`rewards-spec.md` §10), 도감 설명 문구. 쓰는 것: 보상 상태(XP, 레벨, 연속, 업적)는 세션 종료 시 **한 번** 정산(멱등). 정산 함수는 순수 함수(날짜 주입).

## 7. 수용 기준
1. 결과 요약(정답 n/N)이 첫 화면에 스크롤 없이 보이고 XP가 이 단계에 없다.
2. 카드별 정산이 `10 > 5 > 3 > 0`과 같은 순서로 문구를 보인다(깨끗한 정답 +10, 관계 단서 +5, 직접 단서 +3, 오답 +0).
3. 승급·등급 줄이 해당 카드에만 나온다. 단서를 쓴 정답 카드에 "깨끗하게 맞히면 +10"이 있고 오답 카드에는 없다.
4. 레벨업이 없으면 레벨 단계는 막대만, 있으면 새 레벨(여러 단계는 "n → m")과 칭호 변경 시 새 칭호 문구가 보인다.
5. 새 업적이 없으면 업적 단계가 없고, 4개 이상이면 3개 + "그 밖에 n개".
6. 하루 2세션을 넘긴 세션은 XP가 0이고 "경험치는 하루 두 세션까지예요" 문구가 보이며 승급·등급 보너스는 그대로 정산된다.
7. "건너뛰기"로 모든 단계가 정적으로 보이는 최종 상태가 된다. `prefers-reduced-motion`이면 처음부터 정적이다.
8. 같은 세션을 두 번 정산하지 않는다(멱등).
9. 연습·테스트 모드에서는 보상 단계가 없다.
10. 390px 폭에서 가로 스크롤이 없고 모든 버튼이 44px 이상이다.

## 8. 열린 질문
- 자동 진행 옵션과 효과음(후속).
- 카드별 정산이 많은 세션(8장)에서 너무 길지 않은지(사람 반응).
- 업적 문구의 말투를 아트·내러티브와 맞출지(이 문서는 해요체 임시안).
- "깨끗하게 맞히면 +10" 보조 문구가 단서를 막는 압박으로 읽히는지.
