# UX 명세: 타이틀 화면과 나라 선택 (M2)

> **상태**: 초안(2026-11-05, D79-2 → D80). 일반 학습 모드 전용이다. `?study=1`(사람 테스트)에서는 타이틀 없이 진행자 메뉴로 간다.
> **근거**: 사용자 피드백 "시작 페이지가 없다"(D79), `design/game-brief.md` v3, `design/rewards-spec.md`(진행 요약), `design/leitner-spec.md`.
> **UX 명세 표준**: `/ux-design`의 절 구성을 줄여 따랐다. 접근성 요구는 프로젝트 공통 문서(`design/accessibility-requirements.md`)가 없어 이 문서에 최소 요건을 적었다.
> **아트**: 시각 톤은 `design/art/art-bible.md`(한지·먹·인장). 단, 바이블의 화면 규정은 v0 기준이라 이 화면은 M1 뒤에 다시 정한다.

## 1. 목적과 사용자
- **누가**: 한능검을 준비하며 휴대폰 세로로 하루 5~10분 짧게 반복하는 수험생.
- **무엇을 하는가**: 앱을 열면 **무슨 게임인지 알고, 오늘의 학습을 한 번에 시작하거나 이어 하고, 내 진척을 본다.**
- **하지 않는 것**: 광고, 로그인, 상점. 타이틀은 학습 진입을 늦추지 않는다(시작까지 탭 1~2번).

## 2. 화면 흐름

```
앱 열기 ─┬─ (저장 없음) 타이틀(첫 실행) ── 시작하기 → 나라 선택 → (첫 안내 4장, 건너뛰기) → 세션
         └─ (저장 있음) 타이틀(복귀)   ── 이어하기 → 세션   (진행 요약이 보임)
                         ├─ 나라 선택(바꾸기)
                         ├─ 숙련 도감
                         └─ 하는 방법(첫 안내 다시 보기)
세션 끝 → 결과·보상 정산(`rewards-spec.md` §6) → 타이틀로
```

- `?study=1`: 타이틀을 건너뛴다(진행자 메뉴로 직행).
- `?intro=0|1`: 첫 안내 강제(기존 동작 유지). `?title=0`: 타이틀 없이 바로 학습(웹 골격 D82, 개발·e2e용).
- **골격(D82)과의 관계**: 웹 골격은 주 버튼 하나가 "시작하기"(학습 이력 없음)와 "이어하기 · 세션 N"으로 바뀌고, 학습 화면 머리줄에 "처음" 버튼이 있다. 이 명세는 그 구성을 따르되 나라 선택·진행 요약·복귀/쉬는 날 상태를 정의한다.

## 3. 레이아웃 (390px 세로 기준, 와이어프레임)

```
┌────────────────────────────┐
│  [톤 이미지/인장]            │
│  한양 도감                   │  ← 제목(제품명은 확정 전)
│  사료를 읽고 연표에 꽂는      │  ← 한 줄 설명
│  한능검 고대사               │
│                            │
│ ┌ 진행 요약 ──────────────┐ │  ← 저장이 있을 때만
│ │ 서당 학동 · Lv 5          │ │
│ │ ▓▓▓▓▓▓░░░ 72/115 XP     │ │
│ │ 연속 3일 · 오늘 목표 ○    │ │
│ └──────────────────────┘ │
│                            │
│ [   이어하기 · 고구려   ]   │  ← 주 버튼(44px 이상, 오늘 도래 n장)
│ [   나라 바꾸기          ]   │
│ [   숙련 도감            ]   │
│ [   하는 방법            ]   │
│                            │
│ 사실 확인 전 초안입니다      │  ← 늘 표시(M1과 같음)
└────────────────────────────┘
```

첫 실행은 진행 요약이 없고 주 버튼이 **[시작하기]** 하나다.

## 4. 요소

| 요소 | 동작 | 상태/조건 |
|---|---|---|
| **시작하기** | 나라 선택으로 이동, 이후 첫 안내 | 저장 없음일 때만 보임 |
| **이어하기 · 나라** | 마지막에 하던 나라의 오늘 세션을 바로 시작. 보조 줄에 "오늘 복습 n장 · 새 카드 m장". 오늘 목표를 이미 달성했으면 "오늘 목표 완료 · 더 하기" | 저장 있음. 도래·새 카드가 모두 0이면 "오늘은 쉬어도 돼요" 상태로 바뀌고 이어하기는 미리 복습(연습)을 권유 |
| **나라 바꾸기** | 나라 선택 화면 | 항상 |
| **숙련 도감** | 기존 도감 화면 | 항상 |
| **하는 방법** | 첫 실행 안내 4장 다시 보기 | 항상 |
| **진행 요약** | 칭호·레벨, XP 막대, 연속일, 오늘 목표 | 저장 있음(`rewards-spec.md` 저장 데이터). 테스트 모드에서는 없음 |

### 나라 선택

나라마다 **덱과 연표, 간격 반복 일정이 독립**이다(`design/content-plan-m2.md` 3절의 용량 이유). 한 세션은 한 나라에서만 낸다. 하루 목표는 **나라 하나만 해도** 달성된다.

**활성 나라 수에 따라 두 가지 표시**를 쓴다.

| 활성 나라 수 | 표시 | 이유 |
|---|---|---|
| 1~2 | **칩 줄**(웹 골격과 같음). 나라 이름 칩 + 비활성은 "준비 중" 칩 | 한눈에 보이고 공간이 작다 |
| **3 이상** | **나라 목록**(세로 행 하나씩, 행 높이 56px 이상) | 칩 4개 + "준비 중"이 390px에서 줄바꿈되어 어느 것이 선택인지 흐려지고, 나라마다 오늘 할 일을 보여 줘야 한다 |

#### 나라 목록 (3개 이상)
```
┌────────────────────────────┐
│ 나라                          │
│ ● 고구려    36장 중 20 학습     │  ← 선택됨(●, 굵게)
│            오늘 복습 6 · 새 4   │
│ ○ 백제      30장 중 8 학습      │
│            오늘 복습 3 · 새 4   │
│ ○ 신라      준비 중             │  ← 비활성(회색 글자 + "준비 중" 텍스트)
│ 준비 중 1개 ▾                  │  ← 비활성이 2개 이상이면 한 줄로 접는다
└────────────────────────────┘
```

- **행 내용**: 선택 표시(●/○, 색에만 의존하지 않고 `aria-pressed`), 나라 이름, "n장 중 m장 학습", "오늘 복습 a · 새 b"(도래 수와 신규 가능 수). 숙련 개수(금·은·동)는 도감에서 본다(행을 간단히).
- **정렬**: 오늘 할 일이 있는 나라가 위로, 같으면 연표 순서(고구려 → 백제 → 신라 → 가야). 선택한 나라는 항상 맨 위가 아니라 제자리에 둔다(위치가 바뀌면 혼란).
- **추천 표시**: 오늘 도래가 가장 많은 나라 옆에 작은 "오늘 가장 많아요" 텍스트. 선택은 강요하지 않는다.
- **합계 줄**(목록 위): "오늘 복습 모두 9장 · 새 카드 8장". 나라를 다 하면 몇 세션인지 감이 오게 한다(하루 권장 상한 3세션과 연결, `rewards-spec.md` §14).
- **비활성(카드 없음)**: 탭하면 "준비 중입니다. 다른 나라부터 해요." 안내만(화면 전환 없음). 2개 이상이면 접기 행으로 합친다.
- **나라 전환**: 선택은 즉시 반영된다. **진행 중인 세션이 있으면 확인 대화상자**를 먼저 연다: "지금 세션을 끝내고 백제로 옮길까요? 푼 카드는 저장돼요."(D100: 전환 시 진행 중 세션은 종료. 6장 세션이라 손실이 작지만 확인한다.) [옮기기][취소]. 웹 골격은 쿼리 변경과 재로드로 전환하므로 확인 없이 날아가지 않게 한다.
- **키보드·낭독**: 목록은 `role="radiogroup"`, 행은 `role="radio"`(`aria-checked`), 방향키로 이동, 행 이름은 "백제, 30장 중 8장 학습, 오늘 복습 3장 새 카드 4장".
- **칩 줄(1~2개)**은 같은 정보를 칩 아래 한 줄에 요약한다.

#### 연동
- 도감(`design/ux/dogam.md`)의 나라 칩도 3개 이상이면 줄바꿈 칩 줄(도감은 한 나라를 보는 화면이라 목록까지 필요하지 않다).
- 타이틀의 주 버튼은 **선택된 나라** 기준이다: "이어하기 · 고구려"(`D161` 채택안: 버튼 위에 "오늘 복습 n장 · 새 카드 m장 · 약 k분").

## 5. 상태

| 상태 | 화면 |
|---|---|
| 첫 실행 | 진행 요약 없음, [시작하기] |
| 복귀(오늘 목표 전) | 진행 요약, [이어하기 · 나라], 오늘 복습 n장 |
| 복귀(오늘 목표 완료) | 진행 요약에 "오늘 목표 완료", [이어하기]는 "더 하기" |
| 복귀(오래 쉼) | 진행 요약, 한 줄 "다시 오셨네요. 최고 연속 12일." (꾸짖지 않음) |
| 쉬는 날(도래 0) | "오늘은 쉬어도 돼요", 미리 복습(연습) 안내 |
| 저장 손상/읽기 실패 | "기록을 읽지 못했어요. 새로 시작하거나 다시 시도하세요." 두 버튼, 기존 저장을 지우기 전에 확인 |
| 저장소 사용 불가(사생활 보호 창 등) | 한 줄 경고 "기록이 저장되지 않을 수 있어요" 후 계속 진행 |
| 로딩 | 데이터 로딩 중에는 버튼 비활성, 스피너 없이 "불러오는 중" 텍스트 |

## 6. 접근성과 입력 (최소 요건)

- 터치 목표 **44×44px 이상**. 버튼 간격 8px 이상.
- 키보드: 탭 순서는 위에서 아래(진행 요약은 읽기 전용), Enter/Space로 버튼. 포커스 표시를 항상 보인다.
- 화면 낭독: 제목은 `h1`, 진행 요약은 `region`(레이블 "내 진행"), XP 막대는 `progressbar`와 텍스트 값. 이모지·장식 아이콘은 대체 텍스트 없이 숨긴다.
- 색만으로 상태를 전하지 않는다(목표 완료는 텍스트).
- `prefers-reduced-motion`: 막대 채우기 등 애니메이션 없음.
- 글자 크기: 본문 16px 이상, 보조 글자 12px 이상, 큰 글꼴 설정에서 가로 스크롤 없음.
- 한국어 문구는 짧게(버튼 6~8자).

## 7. 데이터

- 읽는 것: 저장된 카드 상태(`leitner-spec.md` §2), 보상 저장(`rewards-spec.md` §10), 마지막으로 연 나라(`last_nation`), 나라별 카드 수.
- 쓰는 것: `last_nation` 한 값. 타이틀은 학습 상태를 바꾸지 않는다.
- 나라별 오늘 도래 수는 순수 함수로 계산한다(`dueCount`).

## 8. 수용 기준 (e2e와 단위)

1. 저장이 없으면 [시작하기]만 보이고 진행 요약이 없다. 저장이 있으면 [이어하기 · 나라]와 진행 요약이 보인다.
2. 390px 폭에서 가로 스크롤이 없고 모든 버튼이 44px 이상이다.
3. [이어하기]는 한 번의 탭으로 세션 화면에 들어간다(오늘 도래·새 카드가 있을 때).
4. 백제·신라·가야는 카드가 없으면 비활성이고 탭해도 화면이 바뀌지 않는다.
5. `?study=1`은 타이틀 없이 진행자 메뉴로 간다.
6. 도래·새 카드가 0이면 "오늘은 쉬어도 돼요"가 보이고 학습 상태를 바꾸지 않는다.
7. 저장소 쓰기가 불가능해도 경고 후 학습이 계속된다.
8. 키보드만으로 모든 버튼에 도달하고, 화면 낭독에서 진행 요약이 의미 있게 읽힌다.
9. 활성 나라가 3개 이상이면 나라 목록으로 바뀌고 각 행에 학습 수와 "오늘 복습 · 새 카드"가 있다. 390px에서 가로 스크롤이 없고 행이 44px 이상이다.
10. 진행 중 세션이 있을 때 나라를 바꾸면 확인 대화상자가 먼저 뜨고 취소하면 세션이 유지된다.
11. 비활성 나라 2개 이상은 접기 행으로 합쳐지고, 탭해도 화면이 바뀌지 않는다.

## 9. 열린 질문
- 제품명(`한양 도감` vs `한능검 연표`)과 톤 이미지: 아트 바이블 재정의 후.
- 나라가 늘면 나라 선택이 목록에서 연표 지도형으로 바뀔지.
- 타이틀에서 오늘의 한 장 같은 콘텐츠를 보일지(진입을 늦추므로 보류).
- 사람 테스트 결과(M1)에서 "이어하기" 단일 버튼이 충분한지.
