# UX 명세: 숙련 도감 (카드 · 업적 · 칭호 · 오답 노트) (M2)

> **상태**: 초안(2026-11-05, D94 후속 → D122). 일반 학습 모드 전용(`?study=1`에서는 숨김).
> **근거**: `design/rewards-spec.md` §3~§5·§10, `design/leitner-spec.md`(등급 §4.1, 오답 노트 §6), `design/ux/title-screen.md`, 웹 골격의 `#dogam`(카드 이름 칩 목록 + 등급 개수).
> **개정 대상**: 이전 도감 규정은 `design/art/art-bible.md` §7의 v0 4×3 격자 도감이다. 학습 모드에서는 **연표 순서의 카드 목록 + 업적 + 칭호 + 오답 노트**로 바꾼다. 아트 바이블의 해당 절은 이 문서 확정 뒤 갱신한다(이 문서가 앞선다).
> **한계**: 시각 디자인은 아트 바이블 재정의 후. 이 문서는 구조, 내용, 문구, 접근성만 정한다.

## 1. 목적
- **내가 얼마나 익혔는지**를 카드 단위로 본다(동·은·금, 아직 안 만난 카드).
- 업적·칭호·레벨로 **진척의 보상**을 확인하고 칭호를 고른다.
- **틀린 카드**를 다시 읽고 연습한다.
- 아는 만큼 채워지는 감각("아는 만큼 도감이 채워진다", 브리프)을 유지한다.

## 2. 화면 구조 (390px 세로, 전체 화면 시트)

위쪽 고정: 제목 "숙련 도감", [닫기]. 그 아래 **프로필 줄**과 **탭 4개**.

```
┌────────────────────────────┐
│ 숙련 도감                [닫기]│
│ 서당 학동 · Lv 6 ▓▓▓░░ 72/175 │  ← 프로필 줄(칭호, 레벨, XP)
│ 연속 3일 · 최고 12일 · 보호권 1│
│ [카드][업적][칭호][오답 노트]   │  ← 탭(44px)
│ ───────────────────────── │
│ (탭 내용: 스크롤)              │
└────────────────────────────┘
```

- 탭 순서와 기본: **카드**(기본), 업적, 칭호, 오답 노트. 마지막으로 연 탭을 기억하지 않는다(열 때마다 카드).
- 프로필 줄은 읽기 전용이다(칭호 변경은 칭호 탭).

## 3. 카드 탭

### 3.1 나라 전환
나라가 둘 이상 활성이면 맨 위에 **나라 선택 칩**(활성인 나라만, 준비 중은 안 보임). 나라가 3개 이상이면 가로 스크롤 없이 줄바꿈하는 칩 줄(`role="group"`). 선택한 나라의 카드만 보인다(기본은 마지막으로 학습한 나라).

- **병행 보기(남북국)**: 선택한 나라가 통일신라 또는 발해이고 두 덱이 모두 활성이면 나라 칩 줄 오른쪽에 [병행 보기] 버튼을 둔다(`design/ux/parallel-timeline.md`). 카드 상세에는 "같은 때 다른 나라는?" 링크.

### 3.2 요약 줄
"고구려 36장 · 금 3 · 은 8 · 동 12 · 익히는 중 5 · 아직 안 만남 8" (텍스트, 색에만 의존하지 않음). 숫자를 누르면 그 등급으로 필터.

### 3.3 목록 (연표 순서)
- **앵커(왕) 줄 + 그 칸의 카드들** 순서로 보인다(연표와 같은 순서). 왕 줄은 접을 수 있다(기본 펼침). 왕 줄에 그 칸의 진행 "3/5" (카드 5장 중 3장 은 이상).
- 카드 줄: `제목 · 등급 · 상자` 한 줄.
  - 등급 표시는 **글자 + 모양**: 동 / 은 / 금. 익히는 중(등급 없음)은 "익히는 중", 아직 안 만난 카드는 "?".
  - **아직 안 만난 카드의 제목은 숨긴다**("? 아직 만나지 않았어요"). 이름이 곧 정답을 알려 주기 때문이다.
  - 밀리거나 오답 노트에 있는 카드에는 작은 "복습" 표시.
- 카드를 누르면 **카드 상세**(시트 안 패널): 제목, 연도(`reign_label`), 해설, 출제 주제(`exam_tags`), 출처(권·조), 등급·상자·다음 도래, 틀린 횟수. 아직 안 만난 카드는 상세가 없다("만나면 열려요").
- 카드 상세에는 **[이 카드만 연습]**(연습 모드, 상태를 바꾸지 않음)이 있다.

### 3.4 필터와 정렬
필터: 전체 / 금 / 은 / 동 / 익히는 중 / 아직 안 만남 / 복습 필요. 정렬은 연표 순서만(변경 없음). 필터를 걸면 왕 줄은 남은 카드가 있는 것만 보인다.

### 3.5 빈 상태
| 상황 | 문구 |
|---|---|
| 아직 한 장도 안 만남 | "아직 만난 카드가 없어요. 첫 세션을 시작해 보세요" + [시작하기] |
| 필터 결과 없음 | "조건에 맞는 카드가 없어요" + [필터 지우기] |
| 나라에 카드 없음(준비 중) | 나라 칩에서 비활성이라 도달 불가 |

## 4. 업적 탭

- **고유 업적 17종** + 나라별 업적(고구려·백제·신라·가야)이 활성 나라 수만큼 늘어난다(`rewards-spec.md` §4).
- 목록 한 줄: `[획득/미획득] 이름 · 한 줄 설명`, 획득한 날짜(획득한 것만), 진행도(해당하는 것만, 예: "연속 3/7일", "동 완성 20/36장").
- **미획득 업적도 조건이 보인다**(숨기지 않는다). 숨은 업적은 두지 않는다(학습 동기를 위해 목표를 알린다).
- 정렬: 획득한 것 위(최근 순), 그다음 진행도가 높은 순, 나머지. 칩으로 필터(전체/획득/미획득/나라별).
- 나라별 업적은 나라 칩 아래에 모아 보인다(나라가 3개 이상이어도 한 줄에 한 업적).
- 설명 문구는 `design/ux/session-result.md` 2.5절의 문구를 그대로 쓴다(결과 화면과 도감의 문구가 같다).

### 업적 표시 문구(요약)
| 상태 | 표시 |
|---|---|
| 획득 | "획득 · 5월 11일" 형태(날짜 서식은 한국어 `n월 n일`) |
| 진행 중 | "연속 3/7일" |
| 미획득, 진행도 없음 | "아직 달성하지 않았어요" |
| 기간 업적(연속 30일 등) 기록 | "최고 기록 12일" |

## 5. 칭호 탭

- 칭호 7종: 입문자(Lv1), 서당 학동(Lv5), 향교 유생(Lv10), 성균관 유생(Lv15), 진사(Lv20), 급제자(Lv30), 대제학(Lv40).
- 한 줄: `칭호 · 필요 레벨 · [사용 중 / 선택]`. 레벨이 안 된 칭호는 "Lv 10에 얻어요"로 잠김(탭하면 안내만).
- 선택하면 프로필 줄과 타이틀 화면에 쓰인다. 기본은 가장 높은 칭호(레벨업 시 자동으로 새 칭호), 사용자가 낮은 칭호를 골라도 레벨업이 이를 덮어쓰지 않는다(`title_pinned`).
- 레벨이 곧 학습 기능을 열지 않으므로 칭호는 **표시용**이다(설명에 한 줄 적는다).

## 6. 오답 노트 탭

`leitner-spec.md` §6: `lapses ≥ 1`이고 현재 상자 ≤ 2인 카드.
- 한 줄: `제목 · 틀린 횟수 · 상자`. 누르면 카드 상세(해설을 다시 읽음).
- 맨 위 [오답 노트 연습] (연습, 상태 불변). 목록 위 안내: "연습은 기록을 바꾸지 않아요. 진짜 복습은 세션에서 돌아와요".
- 상태 표시: 재학습 표시가 붙은 카드에는 "두 번 연속 맞히면 올라가요".
- 빈 상태: "오답 노트가 비어 있어요. 틀렸던 카드를 모두 익혔다면 업적 '오답 노트 비우기'가 열려요" (이모지 없이 텍스트로).

## 7. 접근성

- 탭은 `role="tablist"`/`tab`/`tabpanel`, 방향키로 이동, Enter로 선택. 현재 탭에 `aria-selected`.
- 목록은 `ul`/`li`, 왕 줄은 `button`(`aria-expanded`). 등급은 텍스트로도 읽힌다("금 등급").
- 업적 진행도는 `progressbar` 또는 텍스트로 값 제공. 획득 날짜는 텍스트.
- 터치 목표 44px 이상, 포커스 표시, 색에만 의존하지 않음, 가로 스크롤 없음(390px).
- 긴 목록(카드 36~150장)은 가상화를 쓰더라도 키보드·스크린 리더에 전체 개수를 알린다("36장 중 12장 표시").
- `prefers-reduced-motion`: 접기/펼치기 애니메이션 없음.

## 8. 데이터

- 카드 상태(상자, 등급, 틀린 횟수, 도래): `leitner-spec.md` 저장.
- 보상 상태(XP, 레벨, 연속, 보호권, 업적 획득일, 칭호): `rewards-spec.md` §10. 칭호 선택을 위해 `title_pinned`(null이면 자동)를 추가한다.
- 업적 진행도는 저장 데이터로 계산하는 순수 함수(`progressOf(achievement, state)`)로 구한다(저장하지 않음).
- 카드 목록의 왕 줄 진행 "3/5"는 `answer.after`로 그룹핑해 계산한다.

## 9. 수용 기준

1. 도감을 열면 카드 탭이 보이고 요약 줄의 등급 개수가 목록과 같다.
2. 아직 만나지 않은 카드는 제목이 "?"로 가려지고 상세가 열리지 않는다.
3. 카드 목록이 연표(앵커) 순서이고 왕 줄의 진행 수가 실제 등급과 일치한다.
4. 카드 상세에 해설, 출제 주제, 출처, 등급·상자·다음 도래가 보인다. [이 카드만 연습]은 상태를 바꾸지 않는다.
5. 업적 탭에서 17종(+나라별)이 모두 조건과 함께 보이고, 획득 업적에 날짜, 진행 중에는 진행도가 있다.
6. 칭호 탭에서 레벨이 안 된 칭호는 선택할 수 없고, 선택한 칭호가 프로필 줄에 반영된다. 레벨업이 선택을 덮어쓰지 않는다.
7. 오답 노트가 `lapses ≥ 1 & box ≤ 2` 카드만 보이고, 연습은 상태를 바꾸지 않는다.
8. 나라가 3개 이상이어도 나라 칩이 가로 스크롤 없이 줄바꿈된다.
9. 탭이 키보드와 스크린 리더로 조작된다. 390px에서 가로 스크롤이 없다.
10. 테스트 모드(`?study=1`)에서는 도감이 열리지 않는다(기존 동작).

## 10. 열린 질문
- 카드 일러스트가 생기면 칸 격자형 도감으로 돌아갈지(아트 바이블 재정의 후).
- 나라 간 합산 진척(전체 도감)을 보여 줄지.
- 업적이 늘 때(나라별 4배) 목록이 길어지는 문제: 나라별 접기 등.
- 카드 상세에서 지문 변형(`card-variants-spec.md`)을 보여 줄지(보여 주면 지문 암기 방지 효과가 줄 수 있음).
