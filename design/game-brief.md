# Game Brief: 한양 도감 (v3, 한능검 수험생용)

> **v3 (2026-11-05)**: D56(`docs/decision-log.md`)으로 목표를 "가볍게 복습"에서 **한능검 심화(1급) 수험생**으로 바꾸고 핵심 루프를 (C) 사료 카드 + 왕대 연표 + 간격 반복으로 재설계했다. 이 목표 전환은 메인 디렉터 세션이 위임받아 확정했고, 사용자가 아침에 검토한다. 이전 브리프는 `design/archive/game-brief-v2.md`에 보존했다.
> **v0**(나라×시기 보드, `web/`, `src/`)는 동결이며 이 브리프의 대상이 아니다. v0의 데이터 규칙은 `design/card-data-schema.md`(v1), 새 규칙은 `design/card-data-schema-v2.md`(초안), 간격 반복은 `design/leitner-spec.md`, 첫 검증은 `production/playtest/m1-plan.md`.
> **평가는 가설이다**: 근거인 `docs/reviews/evaluation-hanneungeom.md`는 같은 계열 모델 4개의 의견이고 사람 플레이 기록이 0건이다. M1의 사람 테스트에서 플래시카드보다 낫지 않으면 (C)를 다시 검토한다.

**One-sentence pitch:** 이름이 지워진 사료 속 장면을 읽고 왕대 연표 위에 꽂아 가며, 틀리거나 힌트를 본 카드는 간격 반복으로 다시 만나 한능검 고대사를 몸에 익힌다.

**Target:** 한능검 심화(1~3급, 1급 목표) 수험생. 휴대폰 세로 화면(390px부터 설계), 한 세션 5~10분(추정, M1에서 측정).

## Core loop (학습 모드)
1. **사료 읽기**: 이름·왕명·연도가 지워진 사료 지문(출처 권·조 단위, 원문을 근거로 직접 풀어 쓴 문장)이 카드 앞면이다.
2. **연표에 꽂기**: 나라별 왕대 연표에서 기준 카드(왕대 앵커) 사이의 칸을 골라 꽂는다.
3. **단서는 숙련도 비용**: "기준 사건보다 먼저/나중" 관계 단서(1단계)와 직접 힌트(2단계)를 열 수 있다. 열면 맞혀도 승급이 막히거나 깎인다(`leitner-spec.md`).
4. **공개와 해설**: 정답 칸, 왕대, 연도, 출제 주제(제도·인물·전쟁·문화), 출처가 나온다.
5. **간격 반복**: 틀리거나 힌트를 본 카드는 Leitner 상자(1~5)에서 낮은 상자로 가서 세션 수 간격으로 다시 나온다.
6. **숙련 도감**: 카드마다 동·은·금으로 숙련이 쌓이고, 오답 노트에 틀린 카드가 모인다.

## Modes
| 모드 | 내용 | 상태 |
|---|---|---|
| **학습 모드** | 실패 없음, 먹물 없음, 시간 제한 없음. 5~10분 세션. 간격 반복과 숙련 도감 | **M1·본 구현 대상** |
| **모의시험 모드** | 시간·점수 압박, 먹물류 실패 압박, 숙련된 카드 위주 출제, 5지 선다 변형 | 후속(M1 범위 밖) |
| 클래식 모드(v0) | 나라×시기 보드 | 동결, 후보로만 남김 |

## Player goal & fail state — what "working" looks like
- **학습 모드는 실패 상태가 없다.** 세션을 끝낸 것이 성공이고, 장기 목표는 카드를 동→은→금으로 올리는 것이다.
- **"된다"의 기준**(M1에서 사람이 판단, `m1-plan.md`): 같은 카드를 단순 플래시카드로 학습할 때보다 (1) 놓은 칸의 **근거를 말할 수 있는 비율**, (2) 힌트 없이 맞히는 비율, (3) **다음 날 재인출 정답률**이 같거나 높고, (4) 다시 하고 싶다는 의사가 낮지 않다.
- 틀린 카드는 오답 노트에서 다시 풀 수 있고, 숙련 도감이 진행을 보여 준다.

## MVP — what must exist to be the game
1. **사료 카드 데이터**(스키마 v2, 왕대 앵커 + 사료 카드, 외부 JSON)
2. **왕대 연표 배치 화면**(모바일 세로 390px 우선, 끌어 놓기와 탭 선택 모두)
3. **단서 비용과 해설**(관계·직접 단서의 숙련도 비용, 해설에 왕대·연도·주제·출처)
4. **Leitner 상자와 세션 구성**(세션 수 기준 간격, 세션당 5~10장)
5. **숙련 도감과 오답 노트**(동·은·금)
6. **사실 확인 체계**(2인 확인, 출처 권·조, 기출 표기 대조, 출처 URL 없으면 release 실패, 문구가 바뀌면 `verified` 자동 해제)
7. **저장**(카드 상자 상태와 세션 기록)

M1(고구려 12장 HTML 프로토타입)은 이 중 1·2·3·4의 최소판만 만든다.

## Out of scope — not building this
- 한 번에 전 시대(근현대 포함): 삼국 → 남북국 → 고려 순으로 확장하고 조선 이후는 로드맵 밖이다.
- 학습 모드의 먹물·시간 제한·점수 압박(모의시험 모드에만).
- 기출 문제 풀이 앱의 기능 복제(기출 지문과 해설의 전재). 기출은 표기를 맞추는 참고로만 쓴다.
- 사료 번역문의 그대로 인용(번역문은 별도 저작권, D4). 지문은 원문을 근거로 직접 풀어 쓴다.
- 소셜, 랭킹, 음성 해설, 멀티플레이.
- Godot 빌드의 새 기능(동결, CI만 유지)과 v0 보드의 새 기능.

## Build order
1. **M1**: 고구려 12장 + 왕대 앵커 10장을 만들고 2인 확인 → HTML 프로토타입(연표 꽂기 + 단서 비용 + 간격 반복) → 플래시카드와 비교하는 사람 테스트 → PROCEED/PIVOT/KILL.
2. **M2**: 스키마 v2 확정, 웹 학습 모드 본 구현(모바일 우선), 검증기 v2.
3. **M3**: 삼국 전체(시험 출제 주제 목록 기준). **M4**: 남북국. **M5**: 고려. 단계별 완료 조건은 `docs/roadmap.md`.

---
**Who it's for / what they feel:** 한능검을 준비하는 사람. 사료를 읽고 "아, 이 장면이구나" 하고 알아본 뒤 연표 위 제자리에 꽂는 감각, 그리고 어제 틀린 카드가 오늘 금빛으로 올라오는 뿌듯함.

**Art & audio direction:** 한지·먹·인장의 톤을 유지한다(`design/art/art-bible.md`). 단, 바이블의 보드·도감 화면 규정(§3, §7)은 v0 기준이므로 연표 화면은 M1 뒤에 다시 정한다. 카드 일러스트와 소리는 M1 결과 뒤로 미룬다(v0용 이미지 프롬프트는 보존).

**Reference game:** Timeline(카드를 연표 사이에 꽂는 방식에서 배치 동작만 가져옴), Anki·Leitner 상자(간격 반복의 상자 규칙만), 기존 한능검 앱(기출 풀이와 오답노트형)과는 "사료 속 장면을 알아보는 감각과 사건의 위치 감각을 놀이로 익힌다"는 점에서 다르게 간다(평가 보고서 2.2).

**남은 큰 미정**: 사실 확인을 맡을 사람(사용자가 정함, 사람만 가능), 공식 시험 정보(시간·배점·평가 목표)의 원문 확인(`historyexam.go.kr`는 이 세션에서 접속 불가), 모바일 배포 방식, 사료 번역문의 라이선스.
