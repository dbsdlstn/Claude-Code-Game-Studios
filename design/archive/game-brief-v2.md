# Game Brief: 한양 도감

**One-sentence pitch:** 이름을 숨긴 사건 카드를 단서와 기준 카드와의 관계로 추리해 나라·시기 칸에 놓으며 삼국시대 도감을 완성한다.

## Core loop
- 이름이 숨겨진 카드를 뽑아 단서 1단계(장면 설명)를 읽는다. 필요하면 "단서 더 보기"로 2단계(기준 카드와의 관계)와 3단계(직접 힌트)를 연다.
- 나라(고구려·백제·신라·가야) × 시기(건국기·전성기·결말기) 보드에 놓는다. 보드에는 기준 카드가 미리 놓여 있다.
- 정답이면 카드 이름이 공개되고 도감 칸이 채워지며 해설이 열린다. 오답이면 먹물이 줄고, 정답 칸이 공개되며 카드는 소모된다.

## Player goal & fail state — what "working" looks like
- 판정 대상 카드를 모두 놓아 12칸 도감을 완성하면 클리어.
- 먹물(5)이 0이 되면 해당 라운드 실패, 재도전.
- 시기는 연도가 아니라 사건의 성격으로 판정한다. 건국기=건국 전승과 초창기, 전성기=확장과 번영, 결말기=멸망·통일로 이어지는 마지막 전쟁기(전쟁의 시작·진행·마무리 포함, D45). 열 머리글에 항상 표시한다 (`docs/decision-log.md` D2).

## MVP — what must exist to be the game
1. 카드 데이터 (외부 JSON, `design/card-data-schema.md` 기준)
2. 나라×시기 보드와 기준 카드 선배치
3. 3단계 단서와 "단서 더 보기"
4. 정답 판정, 먹물 5, 오답 시 정답 공개와 카드 소모
5. 도감 수집 화면과 해설
6. 삼국시대 카드 약 36장 (칸당 3장, 학설이 갈리는 카드는 판정 제외)
7. 진행 저장

## Out of scope — not building this
- 삼국 외 시대 (고조선, 고려, 조선 등은 MVP 이후 확장)
- 전투, 경영, 멀티플레이, 음성 해설
- 오답 피드백 세기와 먹물 수 비교 실험 (후속 프로토타입)
- 시간 제한과 점수 압박

## Build order
1. 보드 + 단서 3단계 + 판정 (스키마 기준 카드 12장으로 재확인, 열 머리글 정의 포함)
2. 먹물과 실패 조건
3. 카드 JSON 로딩과 검증 테스트 (헤드리스)
4. 도감 화면과 해설
5. 콘텐츠 36장 (사실 확인 포함)
6. 진행 저장

---
**Who it's for / what they feel:** 한국사를 가볍게 복습하려는 사람. 관계로 칸을 좁히는 추리의 쾌감과 "아는 만큼 도감이 채워지는" 뿌듯함.

**Art & audio direction:** 고지도·한지 질감의 2D 일러스트, 국악 소품. 카드를 잡을 때의 시각 피드백은 연출 단계에서 보충한다.

**Reference game:** Timeline류 카드 게임(근거를 읽고 배치한다)과 The Case of the Golden Idol(단서를 끌어다 놓는 추리). 근거 수준은 `docs/decision-log.md` D3 참고.
